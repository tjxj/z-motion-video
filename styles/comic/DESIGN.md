# 漫画分镜（`comic`）设计说明

## 1. 风格概念
**彩色漫画 / 条漫分镜**。把每一帧口播画面当作一页印刷精致的彩色漫画：整页由粗黑边框与纯白沟槽切分为 1～4 个分镜格，用旁白框、对话气泡、思考云朵和爆炸喊叫框组织信息层级，配合放射速度线、Ben-Day 网点底纹、拟声字贴片与原创 SVG 角色，形成高能量、强叙事感、缩成黑白邮票也能一眼辨认的版式语言。

## 2. 色板与字体
- **色板**：
  - 漫画纸白 `#FFFDF5`（底纸）/ 纯白 `#FFFFFF`（分镜沟槽与对话气泡）
  - 漫画墨黑 `#111111`（粗描边 4～5px、硬黑投影、正文主色）
  - 明黄 `#FFD23F`（旁白框、封面主视觉底、重点高亮色带）
  - 天蓝 `#3FA9F5`（冷色分镜格、对比左侧、常规数据条、科技/速度氛围）
  - 番茄红 `#F2545B`（强调色、`【】` 高亮、爆炸气泡、`VS` 徽章、重点数据项）
  - 网点灰 `rgba(17, 17, 17, 0.12)`（Ben-Day 圆点阴影与边角质感）
- **字体**（`style.json` 加载 `["fun", "comic", "sans", "mono"]`）：
  - 标题 / 气泡主字 / 旁白：`MV Fun`（站酷快乐体）+ `MV Sans` 900 兜底
  - 英文拟声字 / 大数字 / 回目编号：`MV Comic`（Bangers）+ `MV Fun` + `MV Sans` 兜底
  - 正文说明 / 长文本：`MV Sans`（思源黑体 700/500），保证移动端小屏清晰易读
  - 代码：`MV Mono`（JetBrains Mono）+ `MV Sans` 兜底

## 3. 网格与标志性装置
至少包含 5 项专属视觉装置：
1. **粗黑分镜格系统（Comic Panels & Gutters）**：`4.5px solid #111` 粗黑框 + `7px 7px 0 #111` 硬偏移投影 + 白色分镜沟槽，内嵌斜角网点角饰。
2. **四类漫画框体**：
   - 黄色旁白框（`kicker`、小节注、时间戳）
   - 尖角对话气泡（副标题、观点、结尾感言，尾巴指向角色）
   - 云朵思考气泡（`quote` 引用页，三连小圆尾指向角色）
   - 锯齿爆炸气泡（拟声字贴片、`VS` 对决徽章、印章）
3. **拟声字系统（SFX）**：Bangers 英文 + 站酷快乐体中文，粗黑描边 + 错位硬阴影 + 锯齿星爆底；支持场景字段 `sfx` 自定义（写 `false` 可关闭），未写时按模板自动匹配克制的拟声贴片。
4. **速度线与 Ben-Day 网点**：`paint()` 绘制微暖漫画纸与四周淡网点；特写格、封面、章节页、大数字页内置 SVG 放射速度线与斜角网点。
5. **原创 SVG 角色系统**：
   - 示范稿配置 `"mascot": "box"` 时，启用主角纸箱「小箱」（5 种表情：`happy` 开心、`shock` 惊讶、`run` 冲刺、`think` 思考、`proud` 得意），贯穿封面、对话格、特写格、大数字、引用与结尾。
   - 通用稿未配置 `mascot` 时，自动切换为通用漫画符号小助手（带大眼的漫画圆徽章/闪电气泡）与漫画爆发构图，确保任何科普、教程、新闻题材零违和。

## 4. 模板版式语法
- **`cover`（单行本封面）**：顶部全宽漫画刊头条（`VOL.01` + 系列名 + 条码小标）+ 居中/右侧主视觉爆炸大格（放射速度线 + 主角大图或用户配图 + 拟声星爆）+ 粗描边大标题横幅 + 指向主角的白色对话气泡副标题 + 斜贴彩色漫画贴纸 `tags`。支持 `layout: "burst"`（默认）与 `"split"`。
- **`chapter`（回目扉页）**：天蓝/明黄交替满版斜切扉页，超大 Bangers `EP.01` 编号 + 放射速度线 + 粗框白底标题横幅 + 底部黄色旁白框与探头角色。
- **`statement`（漫画大特写）**：上方黄色旁白条 + 中央特写分镜大格（聚焦速度线 + 超大对话/呐喊气泡）+ 角落发言角色。
- **`bignum`（速度线大数字）**：黄色旁白标题 + 放射动作线主分镜格（Bangers 巨型粗描边数字 + 拟声星爆）+ 底部对话气泡解说 + 惊讶表情角色。
- **`stats`（多格数据漫画板）**：2～6 个独立粗黑框分镜格，白/浅黄/浅蓝交错；3 项竖屏采用 1 宽格 + 2 并排格的不规则分镜，重点格切换为明黄/番茄红爆发底。
- **`list`（条漫分格列表）**：每条为独立漫画格，配粗黑序号徽章或漫画红叉/蓝勾贴纸，支持焦点跟随高亮。
- **`steps`（连环画步骤格）**：每步一格带顶部彩色 `STEP 01` 旁白角标，格间由粗黑动感漫画箭头串联。
- **`cards`（漫画设定档案格）**：每卡配左上斜贴漫画标签贴片与角落网点，重点卡切明黄底 + 番茄红角标。
- **`compare`（红蓝对决分镜）**：左天蓝格 vs 右明黄/红格，中央超大锯齿爆炸 `VS` 徽章；胜出方点亮明黄爆发框 + `WIN!` 贴片，底部全宽漫画呐喊结论条。
- **`bars`（漫画能量槽）**：整块速度线大框包裹斜纹漫画能量条，重点条番茄红加尾端星光。
- **`timeline`（漫画旅程轨迹）**：黄色时间戳旁白条 + 白色分镜事件框 + 粗黑折线/实线串联菱形星点。
- **`quote`（云朵名台词气泡）**：超大漫画云朵气泡 + 三连泡泡尾 + 右下角色头像 + 黑底黄字名牌出处。
- **`code` / `formula` / `image`**：分别包装为漫画显示器分镜格、聚焦公式黑板格、纯白内沟粗黑框插画分镜格。
- **`ending`（完结封底）**：明黄速度线底 + `▶ TO BE CONTINUED...` 顶部条 + 大对话气泡 + 挥手角色 + 番茄红行动号召横幅。

## 5. 动效与转场
- **自定义动画**：`comicPop`（弹性微旋弹出）、`comicSlam`（重击砸落回弹）、`bubblePop`（从气泡尾巴处弹出）。
- **持续微动（确定性）**：在 `tick(t)` 中仅由时间 `t` 计算正弦波，驱动拟声字贴片微幅抖动（±2°）与主角轻快呼吸/弹跳，无帧间状态累加。
- **转场**：常规页使用 `push`（`left` / `up` 轮换，模拟漫画切格推进）；进入 `chapter` 章节页切换为 `wipe`（红、黑、黄三色斜条漫画扫幕）。

## 6. 三种画幅适配
- **3:4（1080×1440）**：标准漫画单行本比例。封面上下分层（刊头 → 爆发主视觉 → 标题横幅 → 对话气泡）；内容页上下分镜堆叠，安全区底部留 270px 放漫画字幕条与分格进度条。
- **9:16（1080×1920）**：条漫竖屏比例。充分利用上方与中部纵向空间，封面加大主视觉高度与标题气势，底部严格遵守 560px 安全区，确保不压平台交互区和字幕区。
- **16:9（1920×1080）**：横版漫画跨页构图。封面改为左文（56%）右大主视觉格（44%）的双栏跨页；`statement`、`bignum`、`quote`、`image`、`ending` 切换为左右双分镜构图；`steps`、`timeline` 横向展开为四格连环画横幅。

## 7. 设计取舍记录
- 通用稿适配：为避免在其他题材（如科普、编程）中出现快递纸箱造成违和，纸箱主角「小箱」通过 `story.mascot: "box"` 启用；默认未设置时展示通用的漫画大眼星徽/闪电助手，保留完整漫画分镜语法。
- 字体混排：站酷快乐体（`MV Fun`）圆润有漫画感但字库单字重，因此仅用于标题、气泡主句、旁白标与短标签；正文与多字说明使用思源黑体（`MV Sans`）兜底，保证手机小屏可读性。
