# 孔版印刷（`riso`）设计文档

## 1. 风格概念

**孔版印刷（Risograph）** 源于独立出版物、同人志（Zine）与独立音乐节海报：机器只有两只大豆油墨滚筒——**荧光粉（Fluorescent Pink）**与**孔版蓝（Riso Blue）**，套印在带纸纤维与微颗粒的**暖色再生纸**上。两色重叠处通过 `mix-blend-mode: multiply` 自然叠印出第三色——**深靛紫**，无需额外黑墨，整套画面保持纯粹的双色套印秩序与手作版画质感。

即使缩成黑白邮票大小，也能靠以下**四个专属图形装置**与其他 14 套风格一眼区分：
1. **双色套印错版文字与图腾（Misregistration Overprint）**：主标题、大数字、星芒与太阳图形以蓝粉两版错位 5～7px 叠印，重叠核呈深紫，边缘溢出粉蓝双色油墨边。
2. **印厂套准十字与双色测试条（Registration Chrome）**：四角印刷套准靶标（`⊕`）、左上双色叠印测试圆点（粉+蓝→紫）与页码滚筒编号（`PASS 01/12`），底部为双色叠印网点进度条。
3. **粗网点渐变与大胆几何色块（Halftone & Bold Geometry）**：半圆/同心太阳、12 角星芒、粗波浪声波、网点渐变边带与扁平舞台剪影。
4. **纸色反白贴块（Paper Knockout Blocks）**：大面积几何色块与满版油墨页上，正文统一落在 `#F3EEE3` 再生纸反白方块内，外框采用「蓝实线 + 粉硬错位底影」的双色套印结构，在张扬海报感与手机端高可读性之间取得平衡。

## 2. 色板（严格双色油墨体系）

| 角色 | 色值 | 用途 |
|---|---|---|
| 再生纸底色 `--paper-c` / `--bg` | `#F3EEE3` | 页面底纸、正文反白块、高对比底衬 |
| 荧光粉油墨 `--pink` / `--accent` | `#FF48B0` | 一号滚筒：重点项、高亮、错版副版、贴纸头 |
| 孔版蓝油墨 `--blue` / `--accent2` | `#0078BF` | 二号滚筒：边框、主图形、章扉页满版底、次级条形 |
| 双色叠印深紫 `--ink` / `--fg` | `#1E155C` | 粉+蓝 100% 叠印等效色，用于正文与高对比标题核心，确保手机端清晰易读 |
| 叠印副色 `--fg2` | `#005F99` | 孔版蓝深调，用于副标题、注释、说明文字 |
| 纸面浅蓝灰 `--fg3` | `#6D7EA8` | 弱化文字与未激活符号 |

> **叠色说明**：图形重叠使用真实 CSS `mix-blend-mode: multiply`（蓝油墨约 88% 大豆油墨透明度叠在 `#FF48B0` 上，自然生成浓郁的孔版深紫）。

## 3. 字体体系

在 `style.json` 中声明 `["poster", "black", "sans", "mono"]`：

| 角色 | 字体栈 | 说明 |
|---|---|---|
| 中文大标题 `--f-title` | `"MV Poster", "MV Sans", sans-serif` | 站酷庆科黄油体，敦实圆润的木刻海报字感（单字重 400） |
| 英文与数字 `--f-num` / `--f-kicker` | `"MV Black", "MV Poster", "MV Sans", sans-serif` | Archivo Black，厚重冲击力，用于大数字、时间编号、标签 |
| 正文与字幕 `--f-body` / `--f-subl` | `"MV Sans", sans-serif` | 思源黑体（400/700），手机端小字锐利清晰 |
| 代码 `--f-mono` | `"MV Mono", monospace` | JetBrains Mono，兼容通用稿 `code` 模板 |

## 4. 网格与版式语法（按模板重写）

1. **`cover`（音乐节海报封面）**：
   - 默认支持 `layout: "poster"`（满版海报，默认）与 `layout: "split"`（强左右分栏）。
   - 画面铺设双色套印太阳、同心网点环、12 角星芒与波浪声波；当 `motif: "festival"` 时叠加原创扁平舞台/音箱/人群剪影，否则展示通用几何孔版太阳图腾，保证任意题材（如闰年科普）都饱满完整、下半屏不空。
   - 标题微倾 `-2.2deg`，贴左/上缘排布，带真实双色错版叠印；副标题与标签装入纸色反白「演出信息条」卡片。
2. **`chapter`（蓝墨满版章扉页）**：
   - 整页铺满孔版蓝 `#0078BF` + 底部粗网点渐变，超大荧光粉章节号与底色叠印，章节名落在微倾的再生纸反白大色块内。
3. **`list`（演出阵容表 / Setlist）**：
   - 像音乐节演出阵容表：每行左侧是厚重的蓝/粉编号方块或版画勾选框，右侧是纸色反白信息条（蓝实框 + 粉错位投影）；重点项（`on`）反转为荧光粉满底条。
4. **`bars`（粗颗粒网点条形图）**：
   - 粗大油墨色条叠印粗圆点网纹，外挂错位 `+5px, +4px` 蓝线幽灵框模拟套版错位；重点条为荧光粉叠蓝网点，普通条为孔版蓝。
5. **`cards`（门票与贴纸卡）**：
   - 每张卡片做成带侧边半圆齿孔的音乐节门票/贴纸：顶部彩色票根头（`card-k`）+ 纸色票身 + 双色硬错位底影 + 轻微正负交错倾角。
6. **`timeline`（音乐节日程表）**：
   - 粗双色虚线轨道 + 蓝粉错位叠印靶心圆点，时间戳采用高对比反白胶囊块，事件落在纸色日程条内。
7. **`stats`（双色数据贴块）**：
   - 粉蓝交替色块抬头 + 巨大错版数字 + 底部网点装饰条。
8. **`bignum`（巨幅错版数字海报）**：
   - 背景巨型叠印太阳与星芒，前景超大 `MV Black` 蓝粉错版数字 + 倾斜纸色说明飘带。
9. **`statement`（双色宣言海报）**：
   - 荧光粉主调斜切几何色块 + 纸色反白大字块，【】重点词用孔版蓝油墨色块底衬点亮。
10. **`compare`（粉蓝双滚筒对决）**：
    - 左栏孔版蓝主调、右栏荧光粉主调，中间 12 角星芒 `VS` 叠色章；胜出侧在结论出现时盖上双色套印高亮框。
11. **`steps`（套印流程）**：
    - 蓝粉双圆错位步骤徽章 + 粗虚线油墨箭头 + 纸色步骤卡。
12. **`quote`（独立杂志拉引）**：
    - 巨型错版引号 + 纸色倾斜引文块 + 印章式出处条。
13. **`image`（孔版网点相框）**：
    - 纸色相框 + 孔版蓝粗框 + 荧光粉网点硬阴影 + 四角套准角标。
14. **`code` / `formula`（通用稿兼容）**：
    - 代码窗口采用深靛紫（双墨满印色 `#1D1554`）底板配荧光粉/孔版蓝/纸白高亮；公式置于双色套印相框内，`\hl{}` 点亮荧光粉。
15. **`ending`（返场海报结尾）**：
    - 巨型双色放射星芒太阳 + 错版大标题 + 音乐节手环/票根式 CTA 行动条。

## 5. 动效与转场性格

- **自定义 `risoReg`（错版对准）**：主标题行与大数字出场时，蓝粉两版从较大偏移（`±32px`）快速弹回标准手作微错位（`5px`），模拟双滚筒套准瞬间。
- **自定义 `risoStamp`（滚筒压印）**：卡片、门票、数据块与印章以利落缩放压印落纸，带轻微回弹。
- **自定义 `risoSweep`（刮墨擦出）**：条形图与色带以横向刮墨方式刷出。
- **确定性颗粒微闪（`tick(t)`）**：仅依赖时间 `t`（按 8fps 量化查表），让顶层粗颗粒叠印层做 ±2.5px 极细微位移，并让装饰星芒缓慢匀速旋转，还原孔版逐张印刷的呼吸感。
- **转场**：默认 `paper`（0.62s，像新印好的一张海报从出纸口滑上台面）；章节页切换使用 `columns`（0.65s，模拟滚筒分条印下）。

## 6. 三种画幅适配策略

- **3:4（1080×1440）**：标准独立海报画幅。封面纵向饱满构图（上标题 + 中巨型太阳舞台主视觉 + 下演出信息卡）；列表/条形图/时间线单列大气排布；正文 ≥ 40px，标题 ≥ 84px。
- **9:16（1080×1920）**：竖屏海报重排。充分利用顶部空间放巨型标题与舞台/太阳主视觉，底部严守 `560px` 字幕与平台按钮安全区，卡片与列表加大行距避免拥挤，页脚进度条贴近底部安全边或顶栏不与字幕打架。
- **16:9（1920×1080）**：宽银幕跨页画册/海报双栏重排。封面改为「左 58% 标题信息 + 右 42% 巨型太阳舞台图形」；章扉页改为「左超大错版编号 + 右倾斜纸色标题卡」；步骤与时间线横排，列表多于 4 项自动双栏。

## 7. 设计取舍记录

- **正文颜色选择 `#1E155C`（叠印深靛紫）而非纯蓝或纯粉**：纯荧光粉在暖纸上写小号正文对比度偏低，而真实孔版印刷在正文处常通过高密蓝/双墨叠印获得深紫黑效果，既忠于双色逻辑，又确保手机端阅读清晰。
- **封面通用化机制**：`cover` 默认渲染抽象双色太阳+星芒+声波图腾，使任意题材（如《为什么每四年多出一天》）都呈现完整孔版海报；当场景声明 `"motif": "festival"` 时叠加舞台/音箱/人群剪影，为音乐节示范稿提供专属视觉锚点。
