# 电影胶片（`film`）风格设计文档

## 1. 风格概念

**「35mm 电影片头与幕后放映室」**。整套风格模拟真实 35mm 宽银幕电影胶片在放映机门（film gate）中推进的质感：两侧带齿孔与琥珀色片边码（edge code），上下是深黑遮幅（letterbox matte）承载摄影机监视器信息与影院字幕，中央是带暖钨丝光晕的放映画幅。

即使缩小成邮票并转成黑白，也能一眼凭借以下结构辨认出来：
- 左右双排 **35mm 胶片齿孔带** + 上下高反差 **黑边遮幅**
- 封面中心的 **放映机倒计时片头（Academy Leader 3-2-1 同心准星与雷达扫描）**
- 章节页的 **机械场记板（SVG 拍板斜纹 + 场次/镜次表格）**
- 顶部 **REC 红点 + 24fps SMPTE 时间码（`00:00:12:05`）** 与取景框四角标记
- 银幕光束大数字、胶片帧格条形图与片尾演职员表

## 2. 色板

| 用途 | 颜色 | 说明 |
|---|---|---|
| 遮幅 / 暗房底色 | `#070708` / `#0B0B0C` | 极深近黑，承托黑边与胶片齿孔带 |
| 放映画幅底面 | `#141311` → `#0D0C0B` | 带微弱暖钨丝中心照度的银幕底面 |
| 主强调色（胶片琥珀） | `#E8A33D` | Kodak 胶片边码、重点项、进度条、【】高亮、胜出框 |
| 正文主色（银白） | `#E9E6DF` | 卤化银银幕高光白，护眼且有胶片暖度 |
| 次级文字 / 弱化文字 | `#ACA79D` / `#6E6A63` | 副标题、注释、元数据 |
| 辅助警示色（REC 红） | `#E5383B` | REC 录制红点、场记标号、叉号、关键标记 |
| 辅助冷灰（胶片灰蓝） | `#7D8894` | 非重点条形图、辅助对比项 |

## 3. 字体体系

`style.json` 加载 5 套字体：`["bebas", "elegant", "serif", "sans", "mono"]`。

- **英文大写与大数字**：`"MV Bebas", "MV Sans", sans-serif`（字重 400），用于大数字、帧率指标、场记板表头、胶片片号。
- **中文大标题**：`"MV Elegant", "MV Serif", serif`（字重 400，避免小薇体缺字或字重合成断层），自带影院片头字幕卡的修长雅致感。
- **中文正文与字幕**：`"MV Sans", sans-serif`（正文 400，强调 700），保证手机竖屏清晰可读（3:4 正文 ≥ 42px，标题 ≥ 84px）。
- **引用正文**：`"MV Serif", serif`，强化银幕金句质感。
- **时间码与技术参数**：`"MV Mono", ui-monospace, monospace`，用于 `HH:MM:SS:FF` 24fps 时间码、摄影机参数、代码页。

## 4. 网格与三种画幅适配

三画幅共享 **35mm 纵向走片** 的物理真实结构（真实 35mm 电影胶片齿孔永远在左右两侧，画面上下推进）：

- **3:4（1080×1440）**
  - 左右齿孔轨宽 `54px`，上黑边 `138px`（REC + 拍摄参数 + 时间码），下黑边 `242px`（影院字幕居中于 `--sub-y: 1292px` + 底部胶片卷号进度）。
  - 内容安全区：`--ct: 168px; --cb: 268px; --cl: 84px; --cr: 84px`。
  - 封面、金句、大数字在内容区中构建 **2.39:1 宽银幕发光画框**，上下辅以片头准星与海报演职员栏；多条目内容页自动展开至完整放映窗口，避免拥挤溢出。
- **9:16（1080×1920）**
  - 左右齿孔轨宽 `52px`，上黑边 `210px`，下黑边 `530px`（避让短视频平台底部按钮，字幕落于 `--sub-y: 1456px` 的黑边区内）。
  - 内容安全区：`--ct: 246px; --cb: 560px; --cl: 84px; --cr: 84px`。
  - 纵向空间宽裕，封面采用「顶部倒计时片头准星 + 中部 2.39:1 宽银幕标题卡 + 底部海报演职员栏」三段纵构图。
- **16:9（1920×1080）**
  - 左右齿孔轨宽 `64px`，上黑边 `116px`，下黑边 `184px`（接近真实 2.39:1 宽银幕遮幅比例，字幕在 `--sub-y: 966px`）。
  - 内容安全区：`--ct: 144px; --cb: 204px; --cl: 112px; --cr: 112px`。
  - 封面切换为 **左右双栏宽银幕构图**（左侧倒计时片头准星与技术参数，右侧片头字幕卡）；时间线、步骤、卡片、图文分栏展开为横向电影剪辑台布局。

## 5. 标志性视觉装置

1. **双侧 35mm 胶片齿孔带**：固定于 `#chrome` 左右边缘，含圆角矩形齿孔、琥珀色边码（`35MM · 5219 · 24A ▶`）；换页时与胶片滚动转场严格同步上移。
2. **摄影机取景 HUD 与 24fps 时间码**：左上闪烁 `● REC` 红点与系列片名，右上实时 24fps SMPTE 时间码 `HH:MM:SS:FF`，四角取景框线，底部胶片卷轴进度条。
3. **Academy 倒计时片头（Countdown Leader）**：原创 SVG 同心圆靶标、十字准线与扇形雷达扫描（自定义 `sweep` 动画），作为封面主视觉装置。
4. **SVG 机械场记板（Clapperboard）**：章节页专属，带可动斜纹拍板（自定义 `clap` 动画，先张开后利落合上），下方划分为 `SCENE / TAKE / ROLL / FPS 24` 完整场记格。
5. **胶片颗粒与 24fps 亮度微闪**：`overlay()` 启动时绘制一次高光颗粒与极淡竖向划痕（`mix-blend-mode: screen`）；`tick(t)` 仅基于 `Math.floor(t * 24)` 计算确定性微幅亮度波动。
6. **放映机光束（Projector Beam）**：大数字页从顶央投下锥形暖光束，托起巨幅 Bebas 数字。
7. **胶片帧格条形图**：条形图以连续 35mm 单帧方格 + 上下微齿孔呈现。

## 6. 各模板版式语法

- **`cover`（片头字幕卡）**：支持 `layout: "cinema"`（默认）与 `"split"`。3:4/9:16 为「倒计时准星 + 2.39:1 宽银幕标题卡 + 底部影院演职员标签」；16:9 自动切换左右分栏。带 `image` 时图片嵌于宽银幕取景框中。
- **`chapter`（场记板页）**：全幅居中的机械场记板 SVG + 拍板合拢动画；章节号填入 `SCENE`，标题与注释填入板面主区。
- **`statement`（默片字幕卡）**：深黑遮幅内的双线电影字幕卡边框 + 四角装饰线，居中排大字与高亮词。
- **`bignum`（放映机光束大数字）**：顶部光束锥 + 十字准星框 + 超大 `MV Bebas` 琥珀发光数字 + 胶片规格单位牌。
- **`stats`（摄影机监视器网格）**：暗房监视器分格卡片，每格带 `CH.01` 顶栏与四角短线，重点项亮琥珀边框与红点指示。
- **`list`（分镜通告单）**：左侧 `SH-01` / 胶片光圈标号 + 细横线分隔，焦点跟随（`--dim: 0.44`）时当前项左侧亮琥珀 tally 竖条。
- **`steps`（制片流程）**：圆形光圈编号徽章 + 琥珀剪辑虚线箭头，步骤内容排入暗色制片单格。
- **`cards`（分镜故事板）**：每张卡片顶部带 `FRAME / TAG` 深色胶片眉条，模拟分镜画格。
- **`compare`（AB 审片对比）**：左右双监视器 `REEL A` / `REEL B`，胜出侧在结论出场时亮起琥珀 `FINAL CUT` 边框与底辉。
- **`bars`（胶片帧格条形图）**：每条为带帧隔线与微齿孔的胶片片段，重点项呈琥珀胶片色，其余呈银盐冷灰。
- **`timeline`（剪辑台时间轴）**：每个节点为带琥珀片号的胶片画格卡，由琥珀剪辑线串联；16:9 横排如剪辑台胶片卷。
- **`quote`（银幕引语）**：居中电影取景括号 + 衬线引文 + 演职员风格出处落款。
- **`code` / `formula` / `image`**：分别为「暗房时间码终端」「光学公式暗箱」「35mm 样片放映框」。
- **`ending`（演职员表片尾）**：`— FIN —` 顶标 + 居中片尾主标题 + 演职员样式标签行 + 琥珀边框影院预告框 CTA + 底部制片署名与缓慢上移漂浮动画（`creditDrift`）。

## 7. 动效与转场

- **自定义动画（`MV.kinds`）**：
  - `clap`：场记板顶部拍板从 `-24°` 迅速合拢至 `0°`，带轻微机械回弹。
  - `sweep`：倒计时片头扫描臂与进度环旋转扫过。
  - `beam`：放映机光束柔和展开点亮。
  - `creditDrift`：片尾演职员卡极缓慢向上推进。
- **转场**：
  - 自定义 `MV.transitions.filmroll`（默认，时长 `0.55s`）：模拟 35mm 胶片向上推格，新旧画面之间留出 `3%` 漆黑画幅分界线，并与左右齿孔带同步滚动。
  - 封面进入正文与进入片尾使用 `fade`（黑场叠化），贴合影院片头片尾仪式感。

## 8. 引擎建议

- 当前 `core.js` 的 `#ovl` 在 `base.css` 中写死了 `mix-blend-mode: multiply`，暗色风格需要用 CSS 覆盖成 `screen` 或 `soft-light` 才能呈现浅色胶片颗粒；建议后续可由风格配置 `overlayBlend` 或默认允许 CSS 变量 `--ovl-blend`。
- 转场窗口的实时进度未直接传给 `tick(t, o)`，目前在 `style.js` 中通过读取 `scenes[i].s` 与转场参数重算以同步齿孔滚动；若 `tick` 能收到 `{ transP, transKind }`，同步会更简洁。
