# 购物小票（`receipt`）风格设计文档

## 1. 风格概念
**热敏打印小票 / 柜台账单**：画面是一张铺在灰绿色咖啡柜台桌面上的长条热敏打印小票，所有标题、条目、数据、算式、条形图乃至代码都「打印」在热敏纸上。引文页将小票翻到背面，露出透印的正面淡影与手写圆珠笔批注；对比页把两张小票并排摊在桌面上比价。即使缩成邮票大小并转为黑白，中置锯齿撕边白条 + 星号抬头 + 虚线分隔 + 底部条形码的轮廓也能一眼与其余 14 套风格区分。

## 2. 色板与字体

| 用途 | 色值 | 说明 |
|---|---|---|
| 桌面底色 | `#B9C6BE` | 灰绿哑光柜台桌面（与其余米白/奶油纸风格拉开差距，压出白色小票轮廓） |
| 热敏纸白 | `#FAFAF7` | 略带灰暖调的热敏纸面，带极淡热敏打印微纹与折痕 |
| 小票背面 | `#F2F0E8` | 引用页翻转后的纸背，隐约透出翻转镜像的正面账单字迹 |
| 油墨灰黑 | `#2B2B2B` | 主文字与热敏黑底反白条（纯黑微柔，贴近热敏碳粉观感） |
| 次级油墨 | `#666660` | 时间戳、备注、虚线与辅助信息 |
| 荧光黄 | `#FFF06A` | `【】` 重点词与高亮行的荧光笔横划 |
| 红笔朱红 | `#E0402F` | 手绘红笔圆圈、核对印章、`VS` 标记、重点数值 |

- **字体配置**（`style.json`：`["type", "mono", "sans", "hand"]`）：
  - 数字、时间、价格、条码号、抬头装饰：`MV Type`（Courier Prime）为主，`MV Mono`（JetBrains Mono）兜底，全部开启 `tabular-nums` 等宽对齐。
  - 中文标题与正文：`MV Sans`（思源黑体 400 / 700 / 900），保证手机端高清晰度。
  - 小票背面手写引文与红笔批注：`MV Hand`（霞鹜文楷）配 `MV Sans` 兜底。

## 3. 标志性图形装置
1. **上下锯齿撕边热敏小票纸**：所有内容承载在带真实三角形锯齿撕边与柔和桌面投影的热敏纸条上，3:4 宽 740px、9:16 宽 760px，左右留出桌面呼吸空间。
2. **星号框店名抬头 + 时间戳 + 流水号**：每张小票顶部统一打印 `*** 系列名 ***`、`DATE <日期> HH:MM`（日期取 `story.date`，不写时印 `2026-11-23`）、`NO. #001` 与虚线分隔。
3. **点线引导列（品名 …… 价格/标注）**：列表与数据条目采用「左品名 + 点线填充 + 右等宽数值/状态」的经典小票排布。
4. **ASCII 字符块条形图（`▇▇▇`）**：条形图不用普通色条，而用分段热敏色块模拟字符柱状图，重点行叠加荧光黄横划与红笔数值。
5. **自绘确定性条形码 + 谢谢惠顾**：每张小票底部由 `api.R()` 确定性生成 Code-128 风格 SVG 条形码与编码数字。
6. **荧光笔划过 & 红笔手绘圈**：`【】` 重点采用从左到右刷出的 `#FFF06A` 荧光笔底色；封面合计与大数字页叠加手绘 SVG 红笔圆圈（`rough.circle` + `draw` 描线动画）。

## 4. 模板版式映射

| 模板 | 小票语法 |
|---|---|
| `cover` | 完整海报级小票：星号店名抬头 + 反白类别条 + 大标题 + 双虚线 `TOTAL` 巨型合计框（带红笔手绘圈）+ 明细标签行 + 底部条形码 |
| `chapter` | 换联分界小票：黑底反白大号联次 `NO. 02` + 章节名 + 虚线备注 + 条形码 |
| `statement` | 账单提示联：居中粗体大句 + 荧光笔高亮 + 红笔底线装饰 |
| `bignum` | 合计栏（`TOTAL`）：双线夹巨型等宽数字 + 红笔手绘圆圈 + 单位与算式备注 |
| `stats` | 小计明细联：按行（或 16:9 网格）排列的小计数据，重点项荧光黄标亮 |
| `list` | 小票商品明细：编号/状态符 + 品名 + 点线引导 + 右侧价格或状态，底部附 `SUBTOTAL · 共 N 项` |
| `steps` | 下单打印流程：黑底方标 `[01]` + 虚线箭头连接，焦点跟随高亮当前步 |
| `cards` | 小票优惠券/分联卡：虚线边框 + 剪刀/编号券头 + 重点券荧光黄顶栏 |
| `compare` | **两张小票并排**（微倾 `-1.1°` / `+1.1°`）+ 中央红圈 `VS` + 胜出联红印章 + 底部差额结论条 |
| `bars` | 小票字符块条形图：点阵槽 + 分段黑块 `▇▇▇`，重点行荧光黄底 + 红字数值 |
| `timeline` | 打印时间戳流水：`[08:30]` 等宽时间标签 + 纵向虚线穿孔轴 |
| `quote` | **小票背面手写体**：翻转纸背 + 极淡镜像正面透印 + 霞鹜文楷手写引文 + 红笔印章 |
| `code` | 热敏机自检输出：`POS SELF-TEST` 顶栏 + 浅纸底高对比语法着色 + 荧光黄高亮行 |
| `formula` | 算式核对栏：双横线审计框内嵌 KaTeX 公式 + 荧光黄与红墨高亮 |
| `image` | 小票贴图框：虚线裁切框 + `FIG.` 等宽图注 + 下方/右侧明细要点 |
| `ending` | 结清联：`*** 谢谢惠顾 ***` + 大标题 + 行动号召框 + 红色 `已结清` 印章 + 宽幅条形码 + 署名 |

## 5. 动效与转场
- **出场动效**：自定义 `printLine`（逐行热敏打印：自上而下快速擦出并伴随轻微进纸位移），搭配自定义 `paperFeed`（随条目打印进度，整张小票轻微向下吐纸，全部出场后归零居中）；数字使用 `count` 滚动累加；红笔圆圈与连接线使用 `draw` 描线；`【】` 使用 `mark` 驱动荧光笔由左向右划过。
- **转场**：`push` 向上推入（`dur: 0.55`, `dirs: ['up']`），模拟撕掉上一张小票、新小票从下方吐出。桌面光照仅作左右微弱衰减，避免上下推移时出现接缝。
- **持续动效**：页眉 POS 终端状态点与光标 `▮` 随时间 `t` 确定性闪烁。

## 6. 三种画幅构图策略
- **3:4（1080×1440）**：单张 740px 宽小票居中，左右各留 170px 灰绿桌面；`compare` 铺满 936px 宽度放两张 440px 并排小票；字幕落于小票下方桌面安全区。
- **9:16（1080×1920）**：单张 760px 宽小票置于中上部安全区（`top: 220px ~ bottom: 560px`），充分留出下方字幕区与短视频平台按钮区；条目间距适度放宽。
- **16:9（1920×1080）**：**左右双联桌面构图**（而非简单拉宽一张小票）：左侧为小票抬头联（店名、时间戳、标题、副标题、条形码，宽约 580px），右侧为主内容联或巨型合计联（宽约 960px），封面、大数字、明细、条形图、时间线、卡片均按双联分栏重组，避免 1080px 高度下纵向拥挤。

## 7. 关键取舍
- **桌面色选灰绿 `#B9C6BE` 而非浅木色**：其余风格已有大量米黄/暖白底色，灰绿柜台与 `#FAFAF7` 热敏白纸反差明确，手机缩略图辨识度更高。
- **代码页采用浅底热敏打印风格**：避免与 `night-doc` 雷同，同时高对比红/深蓝/深绿着色配合荧光黄高亮行，保持全片热敏纸材质统一。
- **单价标注**：示范稿中 25 元店购与 5 元自冲均在画面和口播里明确标注「示例价格」，结尾保持中立不算说教账。
