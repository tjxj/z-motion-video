# 手账拼贴（`scrapbook`）设计说明

## 1. 风格概念

**旅行手账本（Travel Scrapbook Spread）**：把每一页视频当成真实摊开的旅行手账页。页面上有奶白点阵纸与装订结构，照片用拍立得斜贴并用半透明和纸胶带固定，关键节点做成带撕口和打孔的票根，路线用图钉和手绘虚线串联，数据与要点做成异形贴纸、撕纸便签和彩色胶带条。整体「贴得满、有层次、带手工温度」，同时保证手机端清晰可读。

## 2. 色板与字体

### 色板
- **底纸**：奶白点阵纸 `#FBF6EC`、暖牛皮纸叠层 `#EFE3CE`、信纸白 `#FFFDF8`
- **主色与文字**：墨炭色 `#3A3A3A`（标题/正文）、暖褐灰 `#6B5E52`（次级）、浅褐 `#9C8E7E`（页脚/辅助）
- **手账胶带与贴纸四色**：胶带粉 `#F6B8C6`、薄荷绿 `#A8DCC8`、柠檬黄 `#FFE27A`、天蓝 `#9CCBEB`
- **强调色**：朱红珊瑚 `#E05263`（用于重点框、邮戳、高亮文字、当前进度点与胜出标记），荧光笔底色 `rgba(255, 226, 122, .72)`

### 字体（`style.json` 加载 `script` / `hand` / `fun` / `sans` / `mono`）
- **手写大标题与拍立得图注**：`"MV Script", "MV Hand", "MV Sans", sans-serif`（龙藏体为主，霞鹜文楷兜底缺字）
- **内容页标题与正文**：`"MV Hand", "MV Sans", sans-serif`（霞鹜文楷，400/700 字重，清晰温润）
- **贴纸数字、角标、圆章**：`"MV Fun", "MV Hand", "MV Sans", sans-serif`（站酷快乐体，圆润俏皮）
- **票根编号、小字说明**：`"MV Sans", sans-serif` 与 `"MV Mono", monospace`

## 3. 标志性视觉装置

1. **真实装订纸面（Binding & Dot-Grid Spread）**：3:4 / 9:16 左侧画金属活页线圈与打孔装订边；16:9 呈现摊开的双跨页中缝折痕与装订线。
2. **斜贴拍立得 + 图案和纸胶带（Tilted Polaroid + Patterned Washi Tape）**：白边拍立得带加宽手写图注底边，四角贴半透明斜纹/波点锯齿胶带；无配图的封面自动生成一张带手绘图案与纸夹的手账拼贴拍立得，保证任何稿子封面都饱满。
3. **锯齿撕口票根（Perforated Travel Ticket Stub）**：带左右半圆缺口、虚线撕口、打孔、编号和日期，用于封面叠贴、章节分隔页、大数字页与对比卡片。
4. **手绘虚线路线图 + 立体图钉（Hand-Drawn Dashed Route & Pushpins）**：时间线和步骤页按 S 形/波浪形手绘虚线串联，每个站点配彩色图钉与斜贴便签。
5. **彩色胶带条形图（Washi-Tape Strip Bars）**：每根柱子是一截带锯齿撕口与不同花纹（斜纹/波点/格纹/波浪）的和纸胶带，出场时像拉胶带一样贴上。
6. **白边异形贴纸与圆形邮戳（Die-Cut Stickers & Round Postmark）**：数据卡、食物贴纸、标签均带粗白边模切效果；页眉页码与封面/结尾配双环水波纹圆形邮戳。
7. **撕纸边便签与打勾清单纸（Torn-Edge Notes & Tear-Off Checklist）**：金句、卡片、列表使用带顶部撕孔或锯齿底边的便签纸与回形针装饰。

| `chapter` | 整张倾斜的旅行船票/登机牌分隔页，左侧编号副券 + 虚线撕口 + 右侧大标题，底纸叠柔和粉/绿/黄/蓝水彩底色 | — |
| `timeline` | 手绘弯曲虚线路线图 + 彩色图钉 + 左右错落斜贴站牌便签（16:9 为横向波浪路线） | — |
| `steps` | 模切圆贴纸编号 + 倾斜便签条 + 手绘弧线虚线箭头 | — |
| `image` | 拍立得相框（双角图案胶带 + 底边手写图注）+ 胶带固定的横线批注便签 | — |
| `bignum` | 复古纪念票根 / 大号邮戳数字框，突出年份与核心数字 | — |
| `statement` | 双层错位撕纸拼贴便利贴（底纸 + 柠檬黄/牛皮纸）+ 对角胶带 + 荧光笔划重点 | — |
| `stats` | 白边模切异形贴纸组（圆章/邮票/胶囊/斜卡轮换），俏皮数字排版 | — |

| `formula` | 贴着天蓝胶带的浅方格演算便签卡 | — |
| `ending` | 手账封底明信片：大邮戳 + 告别手写标题 + 贴纸标签 + 胶带 CTA 条 + 落款 | — |

## 5. 动效、转场与画幅适配

- **自定义动效**：
  - `scrapDrop`：纸片/拍立得/票根从上方带微旋转落下并轻弹贴合。
  - `tapeStick`：和纸胶带从左向右撕拉贴平（用于条形图与胶带标签）。
  - `stickerPop`：贴纸弹性放大并微转贴上。
  - `postmarkStamp`：邮戳盖章落印。
  - `tick` 持续微动：基于时间 `t` 的确定性轻量呼吸微摆，作用于装饰小星星/邮戳，零模糊、零状态累加。
- **自定义转场 `journalFlip`**：模拟手账翻页——新页带轻微角度与页边暖阴影从右侧滑入覆盖旧页，旧页微微压暗退后，全程不透明无透字。
- **三种画幅策略**：
  - **3:4（1080×1440）**：左侧活页线圈装订，封面上下跨区拼贴（上标题、下拍立得与票根压叠），路线图与列表纵向错落排布。
  - **9:16（1080×1920）**：严格避让底部 560px 字幕与平台按钮区，利用纵向高度拉开拍立得与便签层次，路线图纵向展开。
  - **16:9（1920×1080）**：双页摊开手账布局（中缝折痕），封面、图文页、带图卡片页改为左右双栏跨页构图，时间线与步骤改为横向波浪路线。

## 6. 引擎建议

- 当前通过 `STYLE.templates`、`MV.kinds` 与 `MV.transitions` 完整实现了全部定制版式、动效与翻页转场。若引擎未来能在 `api.media()` 中支持自动把 `cap` 放进 `.f-polaroid` 内部底部留白区（目前 `cap` 渲染在 `.frame` 外），各风格拍立得相框可以更少重写 DOM。
