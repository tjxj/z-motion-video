# 方格手稿（`grid-notebook`）设计说明

## 1. 风格概念

**学霸的课堂笔记本**：把口播内容还原成「老师/学霸一边讲课、一边在 5mm 淡蓝方格笔记本上抄写、圈画、打勾、拉箭头写批注」的实时手稿体验。即使缩成邮票大小并转成黑白，依然可以通过**左侧装订孔 + 红竖线页边批注栏 + 封面贴纸标签框 + 回形针/胶带 + 手绘涂鸦与红笔圈画**一眼认出。

## 2. 色板

| 角色 | 色值 | 用途 |
|---|---|---|
| 米白方格纸 `--bg` | `#F5F0E4` | 纸张底色，偏暖不刺眼 |
| 淡蓝方格线 | `rgba(43, 94, 158, 0.10 / 0.21)` | 40px 细格 / 200px 粗格 |
| 墨黑钢笔 `--fg` | `#1D1B18` | 正文、标题主墨色 |
| 铅笔灰 `--fg2` / `--fg3` | `#534D44` / `#8F8679` | 副标题、辅助说明、弱化项 |
| 红笔 `--accent` / `--hl` | `#D7372F` | 页边竖线、批注、圈画、对勾、重点 |
| 蓝铅笔 `--accent2` | `#2B5E9E` | 普通条形图、蓝笔备注、连线箭头 |
| 淡黄荧光 / 胶带 | `rgba(246, 211, 86, 0.42)` / `rgba(218, 195, 138, 0.56)` | 高亮底色、和纸胶带 |
| 便签纸面 `--card-bg` | `#FBF8F0` | 封面标签卡、索引卡片、代码纸片 |

## 3. 字体体系

- **标题与正文**：`"MV Hand", "MV Serif", serif`（霞鹜文楷，工整清秀的课堂手写体，思源宋体兜底）
- **页边红笔批注与手写备注**：`"MV Script", "MV Hand", "MV Serif", serif`（龙藏体，随性批注笔迹，文楷与宋体兜底）
- **页码、编号、日期栏、代码**：`"MV Mono", "MV Hand", monospace`（JetBrains Mono）
- **字幕**：`"MV Hand", "MV Serif", serif`（字重 700，带米白纸面光晕，清晰不糊）

## 4. 网格与标志性装置

1. **红线分栏网格（页边批注栏 + 正文方格栏）**：
   - 底纸采用 40px 方格基准；左侧装订孔（3:4/9:16 沿 `x=28px`，16:9 沿 `x=36px`）配纸脊微阴影。
   - 红色双竖页边线（3:4 与 9:16 在 `x=196px`，16:9 在 `x=276px`）与顶部双横页眉线把每一页分成「窄页边批注栏」和「宽正文方格区」。
   - `kicker`、页码索引、红笔手写短批注（支持场景字段 `margin`，未写时自动提取 `【关键词】` 或按模板生成批注）以及跨红线指向正文的手绘弯曲红箭头均落在页边栏，批注晚半拍出现。
2. **笔记本封面贴纸标签框（含回形针、胶带与手绘涂鸦）**：
   - 封面是一张贴在方格首页上的物理双线标签框（含「科目 / 卷号 / 笔记」表头栏、基线横格大标题），左上夹一枚金属回形针，右上贴一段斜角胶带，下方配索引标签，右下角配原创手绘墨线涂鸦（示范稿为物理灯泡与讲解涂鸦，通用稿自动配钢笔与笔记本涂鸦）。
   - 支持 `d.layout`: `'classic'`（默认贴纸标签框）或 `'split'`（左右分栏，适合带封面图时）。
3. **红笔圈画与动态批注系统**：
   - `【强调词】` 呈现红笔波浪下划线；大数字与重点数字外画手绘红笔椭圆圈；章节页左上角以大号红笔书写「第 1 讲 / Lesson 01」并配手绘双横线。
4. **格子待办清单（动态打勾）**：
   - `list` 每行落在格线基准上，行首为手画方框，讲到时红笔/蓝笔现场打勾（或叉）；编号模式采用红笔手画圆圈序号。
5. **彩铅填格条形图（按格计数）**：
   - `bars` 轨道带方格刻度尺与顶部分格线，柱体呈彩铅斜线排线质感（普通项蓝铅笔、重点项红铅笔），直观按格对比。
6. **对折双栏对比页 + 胜出大红勾**：
   - `compare` 模拟笔记本一页对折：中间有折痕微阴影与手绘竖分界线，红笔圈出 `VS`，胜出方揭晓时动态画出大号红笔对勾并圈亮标题。

## 5. 各模板版式概览

- **cover**：笔记本首页标签框 + 回形针 + 胶带 + 索引标签 + 右下角手绘涂鸦。
- **chapter**：翻开新讲——大号红笔「第 N 讲」/ `Lesson NN` + 手绘双横线 + 大标题 + 蓝笔副记。
- **statement**：大字金句逐行落在方格横线上，页边红笔大括号与箭头指向核心强调词。
- **bignum**：超大红笔数字外包手绘椭圆圈，下接基线说明与蓝笔备注。
- **stats**：笔记本方格数据表卡片，顶部带胶带/红笔角标，重点项加红框与淡黄荧光底。
- **list**：格子待办清单，手画方框讲到时动态打勾（对错模式支持红勾/灰叉）。
- **steps**：红笔手画双圈编号 + 弯曲手绘箭头串联流程。
- **cards**：贴在方格本上的索引便签卡，顶部带彩带/编号角标，重点卡加红笔框。
- **compare**：对折双栏 + 中线折痕 + 胜出方手绘大红勾 + 红笔框结论。
- **bars**：带方格刻度尺的彩铅排线柱状图。
- **timeline**：钢笔时间轴 + 手绘圆环节点 + 框选年份。
- **quote**：左置红笔双竖引线 + 手写引文基线 + 右下龙藏体出处。
- **code**：贴着胶带的浅色方格代码纸片，行号槽 + 钢笔语法配色 + 荧光笔高亮行。
- **formula**：双线定理框 + KaTeX 墨黑公式 + 红笔高亮与下方推导注记。
- **image**：贴胶带的纸片剪贴图 + 蓝笔图注 + 旁列核对要点。
- **ending**：收尾总结页，带贴纸卡片、手绘完成章、标签与红笔下划线 CTA。

## 6. 动效与转场

- **出场性格**：手写感。标题、kicker、列表项采用自定义 `handwrite`（左到右书写擦除+轻微落笔）；红笔圈、箭头、对勾、双横线使用 `draw` 实时描线；页边批注与蓝笔备注晚半拍写出。
- **翻页转场**：自定义 `pageturn` 转场（`dur: 0.62s`），新页带轻微纸页倾角与左侧折页阴影从右向左翻入，旧页微暗轻退，无透底。
- **进度指示**：顶部页眉双线上有一条蓝铅笔刻度线与红笔小三角随全片进度平滑推进。

## 7. 三种画幅适配

- **3:4（1080×1440）**：红竖线 `x=196px`，页边栏宽 `132px`，正文区宽 `788px`（`cl=228, cr=64`）；封面上下构图，标签框居上中，涂鸦居右下。
- **9:16（1080×1920）**：保留底部 `556px` 安全字幕与按钮区；红竖线 `x=196px`，纵向拉大行距与卡片间距，利用上方高挑空间舒展排布。
- **16:9（1920×1080）**：红竖线 `x=276px`，页边栏宽 `192px`，正文区宽 `1504px`（`cl=316, cr=100`）；封面改为左标签框（62%）+ 右涂鸦与标签区（34%）；步骤、时间线、对比、卡片、图片页自动展开为横向多栏构图。

## 8. 引擎建议

- 当前 `MV.transitions` 的 `TPROPS` 白名单仅包含 2D 变换属性（`translate`、`rotate`、`scale`、`clipPath`、`boxShadow`、`filter`、`opacity`），若后续开放 `transform` / `transformOrigin` 或 3D `perspective`，可进一步做出带卷曲透视的真实纸页翻动。
