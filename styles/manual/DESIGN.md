# 装配说明书（`manual`）设计文档

## 1. 风格概念

灵感来自**宜家 / 乐高式装配说明书**与工业技术手册：即使缩成黑白邮票大小，也能靠「粗黑分格线框 + 超大黑色圆形步骤号 + 等粗黑线技术线稿 + 零件清单表 + 对错双格」一眼认出。

彻底抛弃「标题居中 + 下面一大片留白」的通用骨架，把每一页都做成一张真正可以打印装订的技术说明页。

## 2. 色板与材质

| 角色 | 色值 | 用途 |
|---|---|---|
| 说明书白 | `#FBFBF8` | 主纸面底色，叠加 48px 极淡工程十字网格与纸纹噪点 |
| 线稿墨黑 | `#111111` | 等粗边框、技术线稿、超大步骤圆号、主标题 |
| 安全橙 | `#FF5B1F` | 当前高亮步骤、动作箭头、放大镜锚点、章节整页底色（文字高亮用 `#E0440B` 保证对比度） |
| 警示黄 | `#FFC82C` | 警示框斜条纹与警告三角（配 `#111111` 形成黄黑警示带） |
| 蓝图浅灰 | `#EFECE4` | 表头底色、面板辅助区 |
| 对/错语义色 | `#168A4C` / `#D92B2B` | 配合粗黑圆圈 + 几何勾叉，黑白下仍可清晰辨认 |
| 封底墨黑 | `#151515` | `ending` 封底页底色，反白线稿 + 安全橙完成印章 |

## 3. 字体体系

仅使用 `sans`（思源黑体 400/700/900）、`grot`（Inter 400/700/900）、`mono`（JetBrains Mono 400/700）：

- **主标题 / 步骤大号**：`"MV Grot", "MV Sans", sans-serif`，字重 900，紧凑字距
- **正文 / 说明**：`"MV Sans", sans-serif`，字重 500/400，保证移动端 3:4/9:16 正文 ≥ 34px、16:9 ≥ 32px
- **规格代码 / 数量 / 页码**：`"MV Mono", "MV Sans", monospace`（`×2`、`FIG. 03`、`3 / 12`、`STEP 01`）

## 4. 标志性视觉装置（独有）

1. **说明书分格面板（Panel Grid）**：页面主体以 `2.5px solid #111` 细线分成 1～4 格，每格左上角锚定超大黑色圆圈步骤号，讲到哪步该圆圈变安全橙。
2. **说明书封面结构（Manual Cover Sheet）**：外框封套 + 顶部规格栏（左：黑底型号标签；右：人数/耗时小图标框，通用稿自动显示页数/指南图标）+ 中央技术线稿主图与尺寸标线 + 底部等分工具/标签图标栏。
3. **零件清单表（Parts Inventory Grid）**：`cards` 模板改为宜家式表格式网格，每格含小线稿/标号 + 底部或右上角超大 `×2` 数量标识。
4. **对错示范双格（Do / Don't Split Panels）**：`compare` 模板分为左右两格，顶部盖章式超大粗圆圈 `✓` / `✗` 标记，可内嵌对错示意图。
5. **黄黑三角警示框 & 放大镜细节框**：`statement` 采用黄黑斜纹警示条 + 粗黑三角感叹号；`image` / `bignum` 配备工程图版 `FIG.` 头栏与圆形放大镜引线框。
6. **装订外框 Chrome**：四角裁切标记、底部 `3 / 12` 说明书页码、左侧极细刻度尺进度指针。

## 5. 17 个模板版式语法

- **`cover`**：说明书全幅封套。竖屏（3:4、9:16）为「顶栏规格 → 标题区 → 大号技术线稿图框 → 底部工具/标签图标栏」；横屏（16:9）为「顶栏规格 → 左标题+底部工具栏 / 右侧大图框」左右分栏。支持 `specs`（右上角小图标）、`tools`（底栏工具图标+数量）、`image`（主线稿）；通用稿无这些字段时自动回退为页数/手册图标 + 通用机械分解线稿图 + 标签规格栏。
- **`chapter`**：安全橙整页分册隔页，左/上方超大黑底反白 `PART 01` 编号块 + 粗黑分割线 + 标题与备注。
- **`steps`**：说明书核心分格页。1～4 步自动切分为等线框分格（2 步竖屏上下、横屏左右；3 步竖屏三联条/横屏三列；4 步 2×2 网格），每格带大号圆形步骤号（支持 `it.step` 自定义编号），可选内嵌 `it.image` 线稿，格间自动绘制虚线箭头。
- **`cards`**：表格式零件/规格清单。无杂乱阴影，用统一外框与内分割线排成 2×2 / 2×3（竖屏）或 3×2 / 4×1（横屏），每格支持 `it.image` 小线稿与 `it.qty`（如 `×2`）。
- **`compare`**：对错示范 / 规格双格对比。左右并排两个技术面板，自动根据 `ok` / `win` 显示超大圆圈 `✓` / `✗` 盖章标记，支持 `image` 线稿、数值和要点列表，底部横通结论条。
- **`statement`**：黄黑斜纹警示框，左侧/顶部粗黑三角警告标，醒目黑框内大字排版。
- **`bignum`**：工程尺寸标注大数字，上下配游标卡尺双向尺寸线 `|◄───►|` 与技术参数底栏，横屏右侧附圆形工程放大镜图标。
- **`list`**：表格式检查清单，每行带分隔细线，左列为黑圆数字 / 对错圆章 / 橙色三角箭头。
- **`image`**：工程图版 `FIG.` 框，带顶部图号栏与角标十字准星，可选要点说明栏（竖屏上下、横屏左右）。
- **`stats`**：技术参数规格表，每格带 `SPEC 01` 顶部灰条与等宽大数字。
- **`bars`**：带顶部游标刻度尺（0%–100%）的横向工程标尺图，重点项安全橙实心条配卡尺端线。
- **`timeline`**：装配顺序流程框，菱形/六角螺母节点配虚线方向箭头。
- **`quote`**：双线框工程师备忘/口诀卡，左上角带提示图标徽章与右下角 `REF //` 出处。
- **`code`**：深色诊断终端面板，嵌入黑框说明书网格内，高亮行带安全橙边标。
- **`formula`**：蓝图网格计算框，左右工程方括号 `[ ... ]` 与 `CALC // FORMULA` 顶栏。
- **`ending`**：墨黑封底页，居中描线动画完成圆钩（`DONE`）+ 标题 + 标签栏 + 行动提示框 + 真实感 SVG 条形码与页脚编号。
- **`custom`**：沿用说明书字色与网格体系。

## 6. 动效性格与转场

- **转场**：`push`（向左平推，0.55s），模拟翻到说明书下一页。
- **出场动效**：零件与分格用干脆的 `pop` / `drop` 落位；标签与说明用 `wipe` 擦出；虚线箭头与完成勾用 SVG `draw` 描线；对错圆章与印章用 `stamp` 盖章；【】强调词用底部安全橙色带自左向右刷亮。
- **确定性**：所有图形、条形码、纸纹均基于固定种子随机数 `R()` 与时间 `t` 计算，无跨帧状态累加。

## 7. 三种画幅适配

- **3:4（1080×1440）**：主画幅。标准说明书单页比例，封面上下四段饱满铺满，步骤格 2×1 / 3×1 / 2×2，零件表 2×3。
- **9:16（1080×1920）**：预留底部 560px 平台安全区与字幕位；充分利用纵向空间，封面大图加大，步骤格与列表增大行距与图示高度。
- **16:9（1920×1080）**：横版展开说明书（双页摊开感）。封面、章节、图文页、大数字页转为左右分栏；步骤格 2～3 步横向并排；零件表改为 3×2 或 4×1。

## 8. 引擎建议

无阻塞性问题。若未来希望在自定义模板里给子元素内嵌外部图片（如 `steps` / `cards` 里的独立小 SVG）也能自动被引擎 `IMGS` 队列等待解码，可考虑在 `api` 上暴露一个轻量的 `api.img(src)` 辅助方法（区别于带 `220×130` 最小尺寸警告的 `api.media()`）。
