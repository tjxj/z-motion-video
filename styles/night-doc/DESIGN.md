# 夜航文档（night-doc）设计文档

## 1. 风格概念

**深夜写代码**：整个视频画面是一台深夜亮着的深色 IDE 与终端工作台。观众像坐在深夜开发者屏幕前，看着命令被逐字敲下、日志逐行滚出、diff 红绿对照、tmux 多分屏拆解要点，底部状态栏实时显示分支、行列号与进度。

**邮票黑白辨识度**：即使缩成邮票大小并转为黑白，依然能一眼认出——完整的外窗框结构（顶栏标签页 + 左侧行号栏/横屏文件树 + 底栏状态条）、命令行提示符与块状光标、以及高密度的终端卡片/diff/tmux 分屏几何分割。

## 3. 字体系统

在 `style.json` 中仅声明 `["mono", "sans"]`：
- **等宽字体**：`"MV Mono"`（JetBrains Mono）—— 负责命令行、窗口栏、行号、哈希、数字、状态栏、标签、代码与 diff 符号。
- **中文无衬线**：`"MV Sans"`（思源黑体）—— 负责中文标题、正文与字幕，组合写法为 `"MV Mono", "MV Sans", monospace` 与 `"MV Sans", sans-serif`。

字号底线（配合自动缩放确保不溢出）：3:4 / 9:16 正文 ≥ 36px，标题 ≥ 76px；16:9 正文 ≥ 34px。

## 4. 三种画幅网格与窗口骨架

窗口外框（`#chrome`）在转场期间保持稳定，仅内部视口清屏切换，带来真实 IDE 切标签的沉浸感：

- **3:4（1080×1440）**：全幅紧凑 IDE 窗口（外边距 18px）。顶部 56px 标签栏 + 40px 路径面包屑，左侧 64px 行号栏，底部 48px 状态栏。安全区 `--ct: 152px; --cb: 268px; --cl: 112px; --cr: 64px`，字幕位于视口底部 `y=1262px`，不与内容或状态栏重叠。
- **9:16（1080×1920）**：针对短视频平台安全区优化，窗口悬浮于 `top: 108px` 到 `bottom: 316px`，底部留出平台交互区。内部包含顶栏、路径栏、62px 行号栏、正文区（`--ct: 246px; --cb: 560px`）、字幕区（`y=1452px`）以及窗口底部状态栏（`y=1554px`）。
- **16:9（1920×1080）**：完整桌面 IDE 布局。左侧增加 **220px 文件树侧边栏**（列出当前项目各场景对应的虚拟文件并高亮当前页），紧邻 60px 行号栏；正文区 `--cl: 342px; --cr: 80px; --ct: 142px; --cb: 214px`，字幕居中于右侧编辑器视口内。各模板在 16:9 下采用左右分屏（封面双窗格、compare 左右 diff、cards 三列 tmux、steps 横向流水线）。

## 5. 标志性视觉装置（风格专属）

1. **完整 IDE 窗口壳**：红黄绿窗口控制点、动态多标签页（根据当前场景切换文件名）、左侧行号栏（16:9 附带动态文件树）、底部状态栏（`⎇ main` 分支、动态行列号 `Ln/Col`、编码 `UTF-8`、页码与细进度条）。
2. **深夜月亮与终端扫描线**：窗口右上角 / 封面内嵌新月与星点徽章（`☾ 02:14`），叠极微弱的确定性扫描线随时间 `t` 匀速下扫。
3. **命令行标题与闪烁光标**：普通内容页标题带 `$ ` 命令前缀与随时间 `t` 闪烁的实心块状光标 `█`；章节页采用 Markdown `## ` 语法。
4. **开发者专属信息容器**：`git log --oneline` 彩色短哈希列表、`git diff` 红 `-`/绿 `+` 对比视图、tmux 多分屏窗格、命令+灰色输出流、`git log --graph` 提交树。

## 6. 各模板版式语法

| 模板 | night-doc 专属版式 |
|---|---|
| `cover` | 深夜终端主视觉窗口：顶栏 + 右上月亮徽章 + 命令提示符逐字打出标题 + 闪烁光标 + CLI `--flag` 标签 + 下半屏 4~5 行实时滚动日志与迷你 commit 状态面板（16:9 为左右双窗格）。支持 `layout: "compact"` 精简变体。 |
| `chapter` | Markdown 大纲页：大号青/黄/品红 `## 01` 前缀 + 粗体标题 + `────────` 分隔线 + `<!-- note -->` 注释块 + 锚点路径。 |
| `list` | `git log --oneline` 视图：顶部 `$ git log --oneline` 命令条；每行带确定性 7 位彩色短哈希（或对错 `[✓]`/`[✗]` 状态码）、重点项带 `HEAD -> main` 徽章；焦点跟随高亮当前行左侧亮条。 |
| `compare` | Git Diff 视图：顶部 `diff --git a/... b/...` 与 `@@` 区块头；删除侧红框 `-` 行前缀，新增侧绿框 `+` 行前缀，`win` 侧亮起 `MERGEABLE ✓` 徽章，底部 `verdict` 做成 diff summary 条。3:4/9:16 纵向 Unified Diff 保证大字号可读，16:9 左右 Side-by-Side Diff。 |
| `steps` | 终端命令流：每步顶部 `[01] $ 命令标题` + 右侧 `exit 0` 徽章，下方缩进灰色输出 `↳ 说明文字`，步骤间以虚线管道箭头连接；16:9 呈横向 Pipeline。 |
| `cards` | tmux 多分屏终端：外层包裹 tmux 框架，每张卡是一个带 `[0] tag` 窗格标题栏的 pane，重点项标 `ACTIVE`，底部附带 tmux 状态行。 |
| `stats` | 终端监控指标面板（Telemetry Grid）：每格带 `[METRIC_01]` 角标、等宽大数字与底部 ASCII 块状刻度条。 |
| `bignum` | `btop` 风格大盘单指标卡片：顶栏 `[ TELEMETRY // LIVE ]` + 发光等宽大数字 + 块状进度条 + 说明。 |
| `bars` | CLI Benchmark 条形图：顶部 `$ bench --compare` 提示，条形采用终端像素块光栅纹理，高亮项发青光。 |
| `timeline` | `git log --graph` 提交轨道：左侧节点圆点与分支竖线，黄色等宽时间戳/哈希 + 事件文本；16:9 为横向分支轨。 |
| `statement` | 终端 Callout 横幅：左侧青色粗竖线 + `> ` 提示符 + 大字宣言 + 尾部闪烁光标。 |
| `quote` | 文档注释块（Docstring）：`/**` 符号 + 左竖线引文 + `-- source` 等宽署名。 |
| `code` | 原生深色编辑器窗格，带行号、青/品红/黄/绿统一语法色与行高亮。 |
| `formula` | `[ MATH // LaTeX ]` 深色技术文档公式面板。 |
| `image` | 默认使用深色 IDE 预览窗格（`window`），支持图文分栏。 |
| `ending` | 深夜终端收工卡：`[OK] Process exited with code 0` + 标题 + CTA 高亮命令栏 + 署名 + 闪烁光标。 |

## 7. 动效与转场

- **出场性格**：利落、机械、键盘敲击感。`kicker` / 命令提示符用 `type` 打字机出场；标题用 `ndType` / 快速 `slideX`；列表、日志行用自定义 `ndLog`（紧凑快显，模拟 stdout 逐行打印）；卡片与窗格用 `unfold` / 紧凑 `rise`。
- **持续动效（纯时间函数 `t`）**：块状光标 `█` 以 2Hz 频率确定性闪烁（`t=0` 封面常亮）；极淡青色扫描线匀速下移；底栏行列号随时间与场景确定性更新。
- **转场**：快速终端清屏（`fade`，`dur: 0.32`），背景与 IDE 窗口框静止不动，仅内容区清屏重绘。

## 8. 关键取舍

- **竖屏 `compare` 采用上下 Unified Diff**：在 3:4 / 9:16 的 1080px 宽度下，左右两栏加上行号栏容易让长词换行变挤；改为上下堆叠的红 `-` / 绿 `+` Diff 区块，既更像真实 `git diff` 输出，又能维持 38px+ 清晰大字号；16:9 宽屏下恢复经典的左右 Side-by-Side Diff。
- **通用稿兼容性**：对于不含 Git 命令的普通稿件（如闰年科普），窗口标签、伪命令栏和哈希均从当前场景的 `kicker` / `title` / 序号自动生成中性技术文档名称，绝不硬编码 Git 专属文案。
