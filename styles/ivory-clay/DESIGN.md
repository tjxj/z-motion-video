# 象牙陶土（ivory-clay）设计文档

## 1. 风格概念

**温和、克制的 AI 产品发布会**。像一场讲得极好的 keynote：页面呼吸感充足、每页只有一个核心观点、深浅交替建立章节节奏，并用真实感的产品界面装置（对话工作台、开关设置面板、分步引导卡、双对话对比窗口、提示词代码卡）承接内容，而非千篇一律的纯文字居中排布。

在 15 套风格中，本风格与「夜航文档」（极客终端/IDE）和「瑞士网格」（理性几何网格）的区分在于：**暖陶土与象牙纸的温润触感 + 宋体人文标题与极细无衬线数字的反差 + 高完成度圆角产品 UI 装置**。即使缩成黑白邮票，也能凭「左侧/上方大标题 + 圆角产品对话窗口 / 开关面板 / 双窗口对比」的构图一眼辨认。

## 2. 色板

| 角色 | 浅色页（象牙白） | 深色页（深陶土棕） | 说明 |
|---|---|---|---|
| 页面底色 | `#F5F0E8` | `#1F1A17`（附微弱陶土暖光晕） | 浅色承载内容页，深色承载封面/章节/金句/引用/结尾 |
| 卡片 / 窗口表面 | `#FCF9F4` | `#29231F` | 圆角产品面板，柔和阴影与发丝边框 |
| 次级槽位 / 输入框 | `#EDE5D8` | `#342C27` | 对话输入框、进度槽、侧栏底色 |
| 主文字 | `#1F1A17` | `#F5F0E8` | 温暖近黑与柔和象牙白，避免刺眼纯黑白 |
| 次级文字 / 注释 | `#5E554B` / `#8A7F72` | `#CEC5B8` / `#8A7F72` | 灰褐系说明、页码、标签 |
| 强调色（陶土橙） | `#CC785C`（深调 `#B45E41`） | `#D98468`（亮调 `#E49478`） | 状态灯、开关激活、发送按钮、【】高亮、重点标 |

支持每页在 `story.json` 中用 `bg: "light" | "dark" | "clay"` 显式覆写；默认规则为 `cover / chapter / statement / quote / ending` 用深色页，其余内容页用浅色页，自然形成深浅交替的发布会节奏。

## 3. 字体体系

在 `style.json` 中加载 `["serif", "grot", "sans", "mono"]`：

- **大标题 / 金句 / 引用**：`"MV Serif", serif`（字重 600–700，温润人文感，行距 1.2）
- **正文 / 产品界面**：`"MV Grot", "MV Sans", sans-serif`（字重 400–600，干净现代的 UI 质感）
- **巨大数字 / 章节编号 / 指标**：`"MV Grot", "MV Sans", sans-serif`（**极细字重 200–300**，与温厚宋体标题形成高级反差）
- **提示词 / Kicker / 页码 / 元信息**：`"MV Mono", "MV Sans", monospace`

## 4. 网格与画幅适配

- **3:4（1080×1440）**：上下分构。封面为上文（左对齐大标题 + 副标题 + 标签）+ 下方完整产品对话界面卡片；内容页保持充足留白，正文 ≥ 36px，标题 ≥ 78px。
- **9:16（1080×1920）**：充分利用纵深空间，底部保留 560px 平台与字幕安全区；封面产品卡片与内容面板纵向拉展更舒展，避免内容下坠压到字幕。
- **16:9（1920×1080）**：经典 Keynote 左右分栏构图。封面左栏标题区（~47%）+ 右栏带微缩侧边栏的完整产品对话工作台（~53%）；`bignum` 采用左数字右说明分栏；`steps` 与 `timeline` 转为横向分步流；`compare` 为宽幅并排双对话窗口。

## 5. 标志性视觉装置（4 组）

1. **产品对话工作台卡片（Cover / Ending / Image）**：圆角窗口、柔和阴影、顶部状态栏与陶土橙呼吸状态灯、微缩侧边栏（16:9）、用户提问气泡 + 逐字流式生成的助手回复卡片 + 底部带闪烁光标和陶土橙发送按钮（`↑`）的输入框。支持 `d.ui` 自定义对话，也支持在任意通用稿（如 `leap-year`）上根据 `title / sub / tags` 自动生成契合主题的对话预览。
2. **设置面板开关列表（List）**：整个列表收纳于一个圆角设置面板内，顶部带面板标题栏与陶土状态灯；每条记录左侧配真实感拨动开关（Toggle Switch），口播讲到该项时通过自定义动画 `icToggle` 从灰褐滑向陶土橙开启；若条目带 `ok: false` 则保持关闭并显示禁用态，兼顾正反对比列表。
3. **分步引导卡片（Steps）**：每一步呈现为产品新手引导卡，卡片顶栏带 `1 / 4` 等比例胶囊、状态圆点与当前步骤的微缩分段进度条，16:9 横排、3:4/9:16 纵排，配发丝级连接线。
4. **并排双对话窗口对比（Compare）**：左右两个带窗口顶栏的圆角对话面板并排呈现（左侧灰褐低饱和，右侧暖白高质感 + 陶土状态灯）；胜出方（`win: true`）在结论出现时亮起陶土边框与状态胶囊。既适配「模糊提问 vs 清晰提问」的对话对比，也无缝兼容带数值指标的通用对比稿。

## 6. 各模板版式语法

| 模板 | 默认色调 | 版式要点 |
|---|---|---|
| `cover` | 深色 | 支持 `layout: "split"`（默认：标题 + 产品对话工作台）与 `"minimal"`（极简标题 + 底部输入框） |
| `chapter` | 深色 | 左对齐极细巨大章节号（`grot 200`）+ 陶土状态点与延伸细线 + 宋体章节名 + 底部注释 |
| `statement` | 深色 | 带陶土暖光晕的聚光金句页，顶部状态胶囊 kicker + 居中/左对齐大号宋体断行 + 细线注释 |
| `bignum` | 浅色 | 极细超大 `grot 200` 数字 + 陶土单位 + 细分割线 + 说明卡片（16:9 左右分栏，竖屏上下） |
| `stats` | 浅色 | Bento 指标网格：圆角暖白卡 + 右上状态点 + 极细 `grot 250` 数字 + 底部说明；`on: true` 切柔和陶土底 |
| `list` | 浅色 | 设置面板容器 + 逐项拨动开关（`icToggle`），支持 `bullet / number / check / cross` 及 `ok` 混排 |
| `steps` | 浅色 | 产品引导分步卡（`1 / N` 计数胶囊 + 步进微进度条 + 标题与说明） |
| `cards` | 浅色 | 产品特性卡：顶部微工具栏（状态点 + tag 胶囊）+ 宋体标题 + 无衬线正文；重点卡配陶土顶条与浅陶土底 |
| `compare` | 浅色 | 左右并排双产品窗口（顶栏状态点 + 标签/提问区 + 输出要点），胜出侧渐亮陶土高光与徽章 |
| `bars` | 浅色 | 封装在圆角数据面板内：上方「标签 + 极细右对齐数字」，下方胶囊底槽与陶土/暖石填充条 |
| `timeline` | 浅色 | 产品迭代路线图：单色时间胶囊 + 陶土圆环节点 + 圆角里程碑卡片 |
| `quote` | 深色 | 暖深棕卡片内嵌左侧陶土竖线，温润宋体引文 + 等宽出处署名 |
| `code` | 浅色 | AI 产品 Artifact / 提示词代码卡：深棕暖灰代码窗 + 陶土状态灯 + 文件名胶囊 + 逐行打字 + 高亮行 |
| `formula` | 浅色 | 圆角象牙公式展示卡（顶栏状态点 + `FORMULA` 标）+ KaTeX 公式 + 陶土高亮 |
| `image` | 浅色 | 默认 `window` 暖白产品窗口相框，带陶土首圆点与柔和投影 |
| `ending` | 深色 | 左对齐宋体收尾标题 + 暗色互动输入框条（含闪烁光标与发送按钮）+ 陶土 CTA 胶囊 + 署名 |

## 7. 动效与转场

- **转场**：柔和的交叉淡化（`cross`，0.58s），无生硬擦除或黑闪，深浅页过渡顺滑克制。
- **元素出场**：小幅淡入上移（`rise`，距离 20–24px，三阶缓出），节奏从容。
- **标志性微动效**：
  - `icStream`：多行安全的逐字流式输出动画（隐形占位防高度抖动 + 实时层逐字呈现 + 打字末端的陶土色光标），用于封面与对话卡片。
  - `icToggle`：列表开关由关闭平滑拨动到陶土橙开启，与口播同步。
  - `tick(t)`：严格由时间 `t` 驱动的输入框光标温和闪烁与状态灯细微呼吸，保证多进程分段渲染完全确定。

## 8. 引擎建议

- 引擎内置的 `type` 动画依赖横向 `clipPath` 裁切，仅适合单行代码，不适合多行自然换行的对话气泡。本风格通过 `MV.kinds.icStream`（双层占位 + 逐字输出）在 `style.js` 中妥善解决；若未来引擎原生支持多行流式文本动效，对话类风格可直接复用。
