# 杂志瓷蓝（`porcelain`）设计规范

## 1. 风格概念

**青花瓷蓝高端生活方式杂志**（自拟刊名：《器物志 · PORCELAIN FOLIO》）。气质安静、精致、克制而富有文化感，借鉴高端器物杂志与博物馆专刊的编辑排版语法：封面有完整的刊头与器物主视觉，内页像双页跨页（大图版 + 分栏正文 + 首字下沉），用细双线框、青花回纹角饰、缠枝纹流程线和杂志目录体列表建立一眼可辨的视觉秩序。

即使缩成邮票大小并转为黑白，依然能凭「全幅双线刊头 + 中央瓷瓶开光主视觉 + 侧栏要目」「内页细双线框 + 回纹角饰」「目录点线连接 + 右对齐大斜体页码」「缠枝纹曲线工序」与其他 14 套风格清楚区分。

## 2. 色板与明暗节奏

| 用途 | 颜色 | 说明 |
|---|---|---|
| 主底色（瓷白） | `#F6F7F9` | 清透釉白底纸，四角带极克制的浅钴冰裂纹与釉面柔光 |
| 辅助底色（瓷雾） | `#EBF0F7` | 图版底板、对照左栏、代码标本底色 |
| 主强调色（钴蓝） | `#1F3F8F` | 刊头、标题、斜体大数字、缠枝纹、条形图主色 |
| 正文墨色（深靛） | `#16233E` | 高对比度正文与标题墨色 |
| 次级文字（青灰） | `#4E5E7A` | 副标题、注释、页眉页脚 |
| 浅强调色（浅钴蓝） | `#9DB2E0` | 纹样填色、辅助条形、淡色装饰环 |
| 点睛细线（金缮金） | `#B89B5E` | 细双线内框、分割菱形、重点边框（克制使用） |
| 深色跨页（窑蓝） | `#18326F` | `chapter` 章节页与 `ending` 封底页专用深钴底色，文字反白 `#F6F7F9`，金色细线 `#D2B77A` |

> 可在 `story.json` 场景中通过 `"bg": "dark"` 或 `"bg": "light"` 手动切换深蓝跨页与瓷白底页。

## 3. 字体层级

- **标题与刊名**（`--f-title`）：`"MV Elegant", "MV Serif", serif`（站酷小薇 LOGO 体 + 思源宋体兜底），修长优雅的衬线笔画，适合杂志刊头与主标题。
- **正文与引文**（`--f-body` / `--f-quote`）：`"MV Serif", serif`（思源宋体 400/700），阅读安静稳重。
- **数字与英文刊标**（`--f-num` / `--f-ital`）：`"MV Ital", "MV Serif", serif`（Instrument Serif 斜体），用于页码、大数字、目录页号、`ISSUE`、`CONTENTS`、`FIG.` 等杂志标识。
- **小号标注与字幕**（`--f-kicker` / `--f-subl`）：`"MV Sans", "MV Serif", sans-serif`（思源黑体），保证小字号与手机端字幕的锐利度。
- **代码**（`--f-mono`）：`"MV Mono", monospace`（JetBrains Mono）。

## 4. 网格与安全区

- 继承引擎安全区（3:4 上 170 / 下 270 / 左右 84；9:16 上 250 / 下 560 / 左右 80；16:9 上 150 / 下 210 / 左右 150）。
- **细双线框 + 回纹角饰**：在安全区外缘构筑钴蓝 1.5px 外框 + 间距 5px + 金色 1px 内框（内容页显示，封面与深蓝章节页有专属边框），四角嵌自绘 SVG 青花回纹角饰，永不侵入内容区与字幕区。
- **杂志页眉页脚（Folio）**：
  - 内容页顶部：`<刊名> · <小节名>`（左，刊名取 `story.masthead`，示范稿为「器物志」）+ 金色菱形分隔线 + `NO. 04` 斜体页号（右）；封面页隐藏默认页眉，让位给全幅刊头。
  - 底部 Folio：`P. 02 — <刊名>`（左）+ `@你的账号`（右），最底端一条 3px 钴蓝带金点的细进度线。

## 5. 标志性装置（6 项）

1. **全幅杂志刊头与青花器物主视觉（Cover Masthead & Porcelain Plate）**：横贯顶部的双线刊名、期号条、中央双线拱框内的封面图版（给了 image 放图片，没给时放一枚原创 SVG 青花团花开光）、以及带斜体序号的侧栏封面要目（Cover Lines）。
2. **细双线框与青花回纹角饰（Double-Rule Frame & Key-Fret Corners）**：贯穿全片的钴蓝+金缮双细线版心框与四角 SVG 回纹，形成杂志精装书页感。
3. **跨页图版与首字下沉（Editorial Spread & Drop Cap）**：`statement` 等页采用「青花纹样图版 + 分栏正文 + 钴蓝方框首字下沉」的跨页结构。
4. **杂志目录体列表（Contents with Dotted Leaders）**：`list` 呈现为标准杂志目录——左对齐条目与注解、中间点线连接、右对齐大号 `MV Ital` 斜体序号。
5. **缠枝纹工序流（Scrolling Vine Connectors）**：`steps` 与 `timeline` 的连接线由 `link()` 动态生成带卷须与叶片的 SVG 青花缠枝纹，随工序推进逐段描线生长。
6. **双线拉出引文（Editorial Pull Quote）**：`quote` 上下以钴蓝+金缮细双线夹住，中央配莲瓣纹饰与大号斜体引号，左右留白克制。

## 6. 各模板版式语法

| 模板 | 版式设计 |
|---|---|
| `cover` | 顶部全幅双线刊头（刊名取 `story.masthead`，配期号日期）；中部青花器物开光主视觉（支持自定义 `image`，缺省时内置原创 SVG 青花团花开光）；侧边或底栏排布带斜体编号的封面要目。支持 `layout: "editorial"`（默认）与 `"split"` |
| `chapter` | 全幅深窑钴蓝页（`#18326F`），背景叠超大淡蓝斜体序号与 SVG 青花团花纹，金色细双线分隔章节标题与注记 |
| `statement` | 跨页编辑体：青花纹样装饰图版 + 带「首字下沉」大字方框的核心句 + 底部细线注记 |
| `bignum` | 青花开光双线框托起超大 `MV Ital` 斜体数字与金线标注单位，下/右侧配杂志式说明栏 |
| `stats` | 杂志数据账簿：细蓝横竖分割线构成的网格（无厚重阴影），每格配 `FIG. 01` 斜体标号与大斜体数字，重点项以瓷雾底+金顶线突出 |
| `list` | 杂志目录 `CONTENTS`：左侧条目+注解，中间点线引导，右侧大号斜体页码（对错模式保留精细勾叉徽章） |
| `steps` | 双环瓷蓝斜体编号徽章沿 SVG 缠枝纹串联；竖屏单列纵排，16:9 少项横排、6 项自动排成 3×2 杂志跨页矩阵 |
| `timeline` | 沿 SVG 缠枝纹展开，菱形莲蕊节点 + 超大斜体年份/时期 + 宋体说明 |
| `cards` | 专题卡栏：瓷白底板 + 顶部钴蓝/金缮双线 + 左上斜体序号 + 右上莲纹小标，重点卡转为深钴蓝反白 |
| `compare` | 跨页双栏对照：左瓷雾栏、右白瓷栏，中间竖线加青花圆环 `VS` 徽章；胜出方激活钴蓝金边，底部双线裁决栏 |
| `bars` | 瓷蓝色谱条形图：杂志细线表格行 + 序号 + 钴蓝渐变带金端线色条 + 右侧大号斜体数值 |
| `quote` | 居中拉出引文：上下钴蓝+金线双杠、顶部莲纹饰件、大斜体引号、宋体引文与追踪字距出处 |
| `image` | 精装图版框：白卡纸衬边 + 钴蓝内框 + 金色外框 + `FIG.` 斜体图注；带要点时 16:9 左右跨页，竖屏上下排布 |
| `code` | 瓷白学术标本框（`SPECIMEN` 顶栏 + 钴蓝语法配色 + 金色高亮行），摒弃暗黑终端窗感 |
| `formula` | 精装双线公式框 + 四角回纹点缀 + 钴蓝高亮项 |
| `ending` | 深窑钴蓝杂志封底：顶部青花团花徽章、居中大标题、金边标签、瓷框行动号召与底部版权栏（Colophon） |

## 7. 动效与转场

- **转场**：自定义 `magazine` 翻杂志页转场（`MV.transitions.magazine`，时长 `0.72s`）——新页带柔和纸边阴影从右侧优雅翻入，旧页微缩暗化并轻移入书脊，绝无透底。
- **出场性格**：克制、有仪式感。标题与引文用遮罩升起（`mask`），栏目标签用细线擦出（`wipe`），卡片与目录行轻微上浮（`rise`），缠枝纹与框线用 SVG 描线（`draw`）。
- **持续细节**：全部由时间 `t` 确定性驱动（无随机漂移），章节页团花纹随时间极缓慢呼吸旋转（每秒约 1.2°），进度条平滑推进。

## 8. 三种画幅适配

- **3:4（1080×1440）**：经典杂志开本。封面采用「顶部全幅刊头 → 标题与副题 → 中下主视觉图版 + 右侧纵排封面要目」的饱满海报构图；内页上下流式跨页，双线框紧贴版心外缘。
- **9:16（1080×1920）**：高屏杂志特刊，严格避让底部 560px 平台交互与字幕区。封面主视觉居中拉高，封面要目横排在图版下方三栏条带中；列表、工序、条形图适当加大行距，充分利用纵向呼吸感。
- **16:9（1920×1080）**：横版杂志双页跨页（Spread）。封面左栏排刊头、标题与封面要目，右栏整幅展示青花瓷瓶图版；`statement`、`bignum`、`chapter`、`image` 切换为左右跨页分栏；`steps` 6 项切换为 3×2 矩阵。
