# 撞色海报（`color-block`）设计文档

## 1. 风格概念

**运动品牌 Campaign 街头海报**。关键词：**冲、硬、快**。

彻底告别「浅底白纸 + 规整居中卡片」的 PPT 骨架，每一页都像一张直接贴上街头水泥墙的运动宣传海报：高饱和纯色斜切拼接、被画幅边缘硬切掉一半的 300～500px 巨型字与数字、零圆角粗黑硬边横幅、斜放的圆形贴纸徽章、顶部持续高速滚动的运动跑马灯。即使缩成邮票大小并转为黑白，也能靠**斜切对角面 + 出画巨字 + 粗黑条带 + 圆形贴纸**一眼与其余 14 套风格区分。

## 2. 色板与撞色逻辑

五色高纯度运动色板，零渐变、零柔光，靠纯色硬切制造能量感：

| 角色 | 名称 | 色值 | 用途 |
|---|---|---|---|
| 主冲击色 | 荧光黄 Lime | `#E8FF3A` | 封面/结尾大斜切块、高亮底、贴纸、跑马灯 |
| 速度色 | 钴蓝 Blue | `#2340F5` | 章节/大数字/数据对比块、斜切加速带 |
| 热血色 | 番茄红 Red | `#FF4A2E` | 警示/重点条目/引用/高热柱体 |
| 结构黑 | 纯黑 Ink | `#0D0D0F` | 粗边框、偏移硬投影、标签条、跑马灯底 |
| 留白/反差 | 纯白 White | `#FFFFFF` | 信息密集页主底、强对比反色字 |

每页由 `look()` 分配一套 **2～3 色斜切组合**（`ink-lime`、`blue-lime`、`lime-ink`、`red-ink`、`white-blue`、`white-red`），相邻场景强制避开同一主色，并在 `bg` 字段支持手动指定（`ink` / `blue` / `lime` / `red` / `white` / `red-white`）。所有正文均落在实心底色或带粗黑硬边的实心条块内，确保在斜切交界上依然 100% 高对比可读。

## 3. 字体体系

- **中文海报大字**：`"MV Black", "MV Poster", "MV Sans", sans-serif`（`MV Poster` 站酷庆科黄油体写中文大字，生僻字自动回退 `MV Sans` 900 字重）。
- **英文与数字**：`"MV Black", "MV Sans", sans-serif`（Archivo Black 超粗无衬线，所有数字、编号、单位、跑马灯拉丁字符全量拉满厚重感）。
- **正文与字幕**：`"MV Sans", sans-serif`（字重 700/900，紧凑利落，3:4 / 9:16 正文 ≥ 36px，16:9 ≥ 34px）。
- **代码**：`"MV Mono", monospace`。

## 4. 网格与标志性装置（6 项独有语法）

1. **斜切多色块底图（`.cb-bg` / `.cb-slab`）**：用 `clip-path: polygon(...)` 硬切出 2～3 块斜向色块，按模板类型切换切角方向（上斜切、对角劈开、阶梯加速带、左右/上下硬切）。
2. **裁切出画的巨型背景字（`.cb-bleed`）**：320～520px 超大数字或关键词，横向跨边或旋转 90° 竖排压满画幅边缘，放在 `.scene` 装饰层（`.content` 外），既极具张力又不触发内容溢出。
3. **顶部高速跑马灯条带（`.cb-tick`）**：紧贴画幅顶部的黑底荧光黄字（纯黑底页反转黄底黑字）连续滚动条带，印有系列名/标题与 `///` 速度斜杠。
4. **斜置圆形/锯齿贴纸徽章（`.cb-sticker`）**：`-10deg`～`12deg` 倾斜的粗黑边贴纸圆章（用于封面 `GO!` / 首标签、对比 `VS`、章节号标、以及通用 `stamp`），带硬投影并随时间缓慢自转。
5. **粗黑标签条与硬偏移阴影**：所有 `kicker` 采用实心黑底白字/反色斜角标签条；卡片、横幅、柱体统一零圆角、`4px solid #0D0D0F` 粗边与 `7px 7px 0` 硬投影。
6. **封面几何运动主视觉 & 结尾冲线格纹**：封面内置粗线条跑道斜线 + 速度箭簇 + 几何主视觉 SVG（默认是星芒圆章，任何题材都能用；场景写 `"hero": "runner"` 换成冲刺人形，示范稿就是这样）；结尾加入黑白冲线格纹条带（Checkered Flag）。

## 5. 各模板版式语法

| 模板 | 专属版式设计 |
|---|---|
| `cover` | 默认 `layout: "poster"`：黑+荧光黄+钴蓝三色斜切海报；上半/左半超大主标题 + 斜置圆形贴纸；下半/右半压入巨型裁切字 + 粗线条几何跑道与星芒圆章 SVG（`hero: "runner"` 时换成冲刺人形；如有 `image` 则改为硬框海报图）；右侧竖排小字取 `vert`（默认 `POSTER`），圆形贴纸取 `badge`，巨型裁切字取 `bgText`+ 黑底通栏副标题与标签条。支持 `layout: "split"` 双色硬切变体。 |
| `chapter` | 整页高饱和斜切（钴蓝+黄 / 番茄红+黑）；460px 巨型描边+实心重叠章节号跨边裁切；前景黑底粗框大标题块 + 右侧 90° 竖排 `CHAPTER // 01` 侧标。 |
| `statement` | 逐行交错缩进的大字标语条（奇数行/偶数行反色硬块），配合背景速度斜线与 90° 竖排大字。 |
| `bignum` | 巨型数字占满画面主体，背景叠多层超大描边数字底纹，单位做成斜放实心徽章块，底部通栏反色横幅写说明。 |
| `list` | **一行一条全宽粗横幅**，条与条交替高对比底色（纯黑/纯白/荧光黄），左侧粗方格编号块，重点项切为番茄红高亮，奇偶行分别从左/右冲入。 |
| `bars` | **粗壮色块柱（高 80～98px）+ 超大压出数值**：柱体带粗黑硬框与斜纹高光，右侧数值字号大于柱高、上下微压出柱体边缘并用反色描边突出。 |
| `compare` | **整页双色硬切**：3:4 / 9:16 上下斜向硬切两块饱和底色（空间充裕不挤字），16:9 左右对半硬切；中心压大号旋转 `VS` 贴纸章，底部通栏斜角结论条，胜出方点亮粗框与 `WIN` 徽章。 |
| `steps` | 赛道号码布风格：平行四边形斜切序号牌 `01`/`02` + 粗框色块卡 + 硬折线粗箭头连接，竖屏左右微错位推进，横屏起跑线式横排。 |
| `cards` | 零圆角街头贴纸卡墙：左上角冲出卡片边界的反色编号/标签块 + `7px` 硬投影，重点卡整块反色微倾。 |
| `stats` | 粗黑框撞色数据矩阵：每格右上角带斜切色角，巨型 `MV Black` 数值占满格宽，重点格整块荧光黄/番茄红反色。 |
| `timeline` | 粗黑/亮黄贯穿赛道轴线 + 菱形实心里程标 + 反色年份标牌 + 粗框事件横条。 |
| `quote` | 整页红黑/蓝黄斜切 + 360px 巨型实心斜体引号 + 逐行粗框大字宣言 + 右下角黑底出处条。 |
| `code` | 纯黑+荧光黄硬核海报终端框：三个直角方块替代圆点，右上角亮黄文件名标签条，高亮行荧光黄左粗杠。 |
| `formula` | 白底蓝黄大斜切，公式置入粗黑框+硬投影大白牌，`\hl{}` 荧光黄高亮块。 |
| `image` | 5px 纯黑框 + 10px 硬投影 + 左上角斜贴纸标牌；配要点时要点自动走撞色紧凑横幅。 |
| `ending` | 黑底荧光黄斜切 + 巨大背景 `GO!` 裁切字 + 黑白冲线格纹饰带 + 超大结尾标语 + 荧光黄粗框行动号召横幅按钮。 |

## 6. 动效与转场

- **转场**：四色斜条擦除 `wipe`（纯黑 + 荧光黄 + 钴蓝 + 番茄红，`skew: 16deg`，`dur: 0.52s`，`sw: 0.5`），利落呼啸扫过画面。
- **出场动效**：节奏极快（0.32s～0.45s），自定义 `cbSlam`（标题砸下回弹）、`cbBanner`（列表横幅奇偶左右双向冲入）、`cbPunch`（卡片爆发切入），配合 `slam` / `stamp` / `wipe`。
- **持续动效（纯时间函数）**：顶部跑马灯高速滚动；贴纸徽章缓慢匀速旋转；底部/顶部细长分段进度条实时推进。

## 7. 三种画幅构图策略

- **3:4（1080×1440）**：主构图。上主标题 + 下主视觉/内容，高反差黑底白框页码与小节条居底部安全区外，字幕黑底粗框条居 `--sub-y`。
- **9:16（1080×1920）**：针对底部 560px 平台按钮与字幕区专门重构——内容严格锁在安全区内并拉大纵向节奏；顶部跑马灯与底部页码进度条构成完整海报上下压边画框。
- **16:9（1920×1080）**：真正横屏分栏重构——封面采用「左 54% 标题与标签 / 右 46% 斜切主视觉与巨字」；`compare` 切换为整页左右对半硬切；`steps`、`timeline` 横排赛道推进；`list` 5 项以上自动双列横幅。

## 8. 引擎建议

- 目前背景斜切层和出画巨字通过挂在 `sc.el`（`.content` 外）避开 `fitScene` 溢出检测，运转稳定；若未来引擎能对 `.cb-deco` 类元素提供原生 `data-ignore-overflow` 标记，则自定义模板内部也可以更自由地做局部出画元素。
