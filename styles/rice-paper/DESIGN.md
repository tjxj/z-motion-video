# 宋式米纸（`rice-paper`）设计说明

## 1. 风格概念

**宋画册页 × 书法题跋 × 传统装裱**。
以南宋小品画册页与立轴挂画为灵感，奉行「计白当黑」的东方构图哲学：右侧竖排书法立骨，左侧大面积宣纸留白与淡墨远山造境，朱砂篆印压角定气韵。文字阅读顺序尊重传统手卷与竖排习惯（从右往左、自上而下），在 3:4 呈挂轴册页、9:16 呈高挑立轴、16:9 呈横向长卷。

## 2. 色板

| 用途 | 色值 | 说明 |
|---|---|---|
| 宣纸底色 `--bg` | `#F4EDE0` | 温润熟宣米色，叠纤维与淡茶晕染 |
| 绫边装裱 `--silk` | `#E8DEC9` | 天头地脚与画框绫边 |
| 笺纸底色 `--card-bg` | `rgba(252, 248, 240, 0.78)` | 题签、册页卡片底 |
| 焦墨主字 `--fg` | `#1F1B18` | 书法主标题与核心文字 |
| 重墨次字 `--fg2` | `#5F554A` | 副题、题跋、说明 |
| 淡墨辅字 `--fg3` | `#96897A` | 乌丝栏线、页码、注脚 |
| 朱砂强调 `--accent` | `#B5302A` | 印章、朱批圈点、焦点高亮、进度朱点 |
| 石青辅色 `--accent2` | `#3E5D6B` | 远黛山水、常规墨条、时令刻度、代码函数 |
| 藤黄微点 `--ochre` | `#9C7A40` | 极克制用于装裱角饰与秋令标色 |

## 3. 字体体系

- **书法主字** `--f-brush`：`"MV Brush", "MV Serif", serif`（马善政毛笔楷书，单字重 400）—— 封面大标题、章节卷号与题名、金句、引文、超大中文数字、结语。
- **小标题与题签** `--f-elegant`：`"MV Elegant", "MV Serif", serif`（站酷小薇 LOGO 体，单字重 400）—— `kicker` 题签、卡片角标、页眉卷名、标签。
- **正文与字幕** `--f-body`：`"MV Serif", serif`（思源宋体 400 / 700 / 900）—— 列表、卡片正文、题跋说明、数字与字幕。
- **代码等宽** `--f-mono`：`"MV Mono", "MV Serif", ui-monospace, monospace`（JetBrains Mono）—— 代码页。

## 4. 网格与三种画幅重排

- **3:4（1080×1440，册页立轴）**：四边留装裱子母双线框与天地头；封面/金句/引用/结尾采用「右 42% 竖排书法 + 左 58% 水墨山水留白与左下朱印」的非对称构图；列表与短时间线采用从右往左展开的乌丝栏竖列。
- **9:16（1080×1920，高挂立轴）**：顶部加装裱玉池天头与细惊燕带，安全区底部严格避让 560px 平台与字幕区，竖排书法拉长纵向气势，水墨远山稳托于字幕区之上。
- **16:9（1920×1080，横向长卷）**：左右两端置仿古红木卷轴轴头与绫边包首，成为真正的横向手卷；封面「右三成题书 + 左七成绵延山水长卷」；内容页（数据卡、条形图、列表、时间线、卡片）优先采用「右侧竖排题柱 + 左侧展开内容区」的非对称卷轴网格。

## 5. 标志性装置（独有视觉语法）

1. **立轴 / 手卷装裱与右起进度墨线**：3:4 / 9:16 呈立轴天地头，16:9 呈带木轴头的横向长卷；进度条置于顶部/底框，以极细淡墨线配合**从右往左移动的朱砂印点**记录阅读进程，页码以中文数字呈现（如 `一 · 十二`）。
2. **右侧竖排书法 + 左侧水墨意境画**：原创淡墨远山、烟岚、孤月、飞鸟（`tick(t)` 确定性驱动飞鸟与淡云微移），形成邮票尺寸黑白化仍可一眼辨识的构图指纹。
3. **乌丝栏手卷竖排（List / Timeline）**：从右往左一列一列展开，细墨竖界线分隔，顶端配朱砂中文序印；当内容为长句、多条或英文数字混排时，自动优雅切换为古籍横栏笺纸以防溢出。
4. **圆形「时令盘」（`cards` 的 `layout: "wheel"` 变体）**：仿宋代星象历盘的淡墨双环二十四刻度圆盘，中心朱砂圆印，四周排布四季/循环主题签卡，并带指针连线。
5. **朱砂印章体系与朱批圈点**：封面与结尾落 `story.seal` 白文方印（微残石刻边 + 正片叠底）；章节页配朱砂椭圆引首章；`【重点词】` 渲染为朱砂字色 + 侧边朱砂圈点着重号，绝不使用现代荧光笔；简洁整数自动配中文数字主视觉与小字阿拉伯数字刻度。

## 6. 各模板版式设计

- **`cover`**：默认 `'scroll'`（右竖排书法大字 + 右侧引首竖签 + 左侧副题 + 左侧大留白远山孤月飞鸟 + 左下朱砂大印与落款）；支持 `layout: "center"`（居中匾额）。
- **`chapter`**：极淡青烟宣纸底 + 横贯画面的水墨飞白大笔触 + 右侧竖排「卷一 / 卷二」配朱砂椭圆引首章 + 竖排章节名 + 左侧竖排题跋。
- **`statement`**：右侧起多列竖排书法大字，乌丝栏淡墨竖线分隔，左侧大留白点缀淡墨云影/竹石，左下小字注记。
- **`bignum`**：中左淡墨日晷圆环刻度衬托主数字（简洁整数自动显示超大书法中文数字 + 小字阿拉伯数字标尺；高精度小数保留衬线大字与计数动画），右侧竖排题签与解读。
- **`stats`**：古籍双线宣纸笺格（带鱼尾角饰）；16:9 右题左格，简洁整数附右上角淡墨中文数字印记，重点项配朱砂竖签框。
- **`list`**：短中条目（≤5 项）默认「从右往左展开的乌丝栏手卷竖列」；长句/多条/拉丁词较多的通用稿自动切换为「宋版刻本横栏笺」；支持 `layout: "scroll" | "rows"` 手动指定。
- **`timeline`**：16:9 横向手卷自右向左画墨线；3:4 / 9:16 短条目走手卷竖排年表，长条目走「右朱砂纪年碑 + 墨线 + 左史事笺」错落版式。
- **`cards`**：默认宋笺题签（右侧嵌竖排朱砂角标条）；`layout: "wheel"` 启用圆形「时令盘」构图。
- **`quote`**：纯粹竖排书法引文，首尾朱砂直角引号「『…』」，左侧竖排小楷出处与朱砂小闲章，左方大片留白。
- **`bars`**：松烟淡墨笔刷条（重点项朱砂墨条），配乌丝刻度线与末端朱砂标尺竖线；16:9 右竖题左图。
- **`steps`**：朱砂八角/方印中文数字徽章 + 淡墨手绘连线，16:9 右竖题左步序。
- **`compare`**：宋画册页左右对开折页，中缝双线与古籍鱼尾，中央压朱砂圆印（默认「对」，尊重 `d.vs`），胜出方右上角盖朱砂「胜」印框。
- **`image`**：宋代绫边镜心装裱框；16:9 左画右跋，竖屏上画下跋。
- **`code` / `formula`**：暖白素笺雕版代码窗（国画矿石色高亮）与古籍算经双线框。
- **`ending`**：右侧竖排书法结语 + 左侧跋文、标签、署名 + 左下重落朱砂大印与淡墨山水收尾。

## 7. 动效与转场

- **自定义动效**：
  - `brushDown`：书法竖列自上而下挥毫显现（裁切展开 + 柔和淡入）。
  - `scrollUnroll`：手卷与横墨笔触从右往左徐徐展开。
  - `ink`：墨迹在宣纸上由微晕收敛至清晰。
  - `stamp`：朱砂印章落下回弹定格。
  - `tick(t)` 持续微动：封面/结尾的淡墨飞鸟与远岚按时间 `t` 确定性极缓漂移。
- **转场**：自定义 `inkWash`（墨色晕染叠化，0.85s，平滑过渡无闪屏与透底）。

## 8. 取舍与说明

- 通用稿（如 `leap-year`）中存在带 4 位小数（`365.2422`）或较长说明的列表/时间线。为同时满足「宋画竖排神韵」与「通用稿清晰零溢出」，数字转换仅对 ≤ 9999 的纯整数启用中文主数字，高精度小数保留精确阿拉伯数字与计数动画；列表与时间线自动按内容长度与条数决定乌丝竖卷或古籍横笺，保证手机端正文 ≥ 34px 且无溢出告警。
