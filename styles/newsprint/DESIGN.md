# 报纸号外（newsprint）设计说明

## 1. 风格概念
**老报纸头版与特刊版面**。每一页都按一张完整的复古铅字印刷报纸来排：头版有报头、报耳、通栏大标题、网点传真照片和带竖向栏线的多栏实文；内页按内容角色切换为不同新闻版面（专版导读、人物方框版、数据公报表格、时序日程表、引语框、传真摄影版、印刷图表版、终版剪报回执），右上角标「第 XX 版」，底部带「下转第 XX 版 ▶」。即使缩成邮票大小并转为黑白，也能凭借报头双线、多栏竖线、黑框题头与网点插图一眼认出。

## 2. 色板与纸面质感
| 角色 | 色值 | 用途 |
|---|---|---|
| 旧报纸米黄 `--bg` | `#EFE6D2` | 主纸面底色 |
| 报纸浅灰黄 `--bg-box` | `#E5D9BF` | 表格题头、侧栏导读盒、引语框底 |
| 剪报高光纸 `--bg-paper` | `#F6EFE0` | 传真照片框、电报代码纸面 |
| 油墨黑 `--fg` | `#1A1A1A` | 铅字标题、正文、双线框、栏线 |
| 次级墨色 `--fg2` | `#4A443A` | 副题、图注、页眉页脚说明 |
| 铅灰 `--fg3` | `#7D7567` | 辅助标号、虚线网格、次要信息 |
| 套红 `--accent` / `--hl` | `#C41E1A` | 「号外」印章、重点栏目、强调词、高光数据与条形 |
| 专版黑底（`chapter`） | `#1A1917` | 章节专版反白铅字底色，文字用 `#EFE6D2`，套红 `#D93829` |

- **底纸（`paint` 一次绘制）**：米黄底色 + 1400 条细纸浆纤维 + 350 个印刷油墨微粒 + 边缘微泛黄暗角 + 折痕（竖版横向中折、横版纵向中折）+ 四角印刷套准十字标 + 纸面噪点。
- **叠层（`overlay` 一次绘制）**：细颗粒正片叠底，使纯黑与套红油墨都带有印在新闻纸上的咬合质感。

## 3. 字体层级
- **标题 / 报头 / 正文（`serif` · `"MV Serif"` 思源宋体）**：标题 900 极粗宋体，正文 500/700，确保手机小屏下 34px+ 依然清晰锐利。
- **日期 / 版次 / 大数字 / 英文（`cond` · `"MV Cond"` Oswald，兜底 `"MV Sans"`）**：高挑窄体数字，强化老报纸数字公报与版次编号的秩序感。
- **图注 / 电讯稿 / 代码（`type` · `"MV Type"` Courier Prime，兜底 `"MV Sans"`）**：打字机电报质感，用于图片图注、电讯时间码与代码窗口。
- **标签辅助（`sans` · `"MV Sans"`）**：作为窄体与打字机体的中文兜底及紧凑栏标。

## 4. 标志性装置（6 项）
1. **头版大报头 + 左右报耳（Masthead & Ears）**：头版顶部左右双框报耳（「号外特刊」「第 01 版」），中央通栏 900 极粗刊名（读取 `story.masthead`），下方 `4px + 1.5px` 经典粗细双线夹日期 / 期号 / 系列栏。
2. **内页报眉与转版脚注（Running Folio & Jump Line）**：内页顶部显示刊名、当前版面名（按模板与小节自动映射如「人物专版」「数据公报」「时序日程」）和黑框「第 XX 版」；底部页脚显示署名、细进度墨线及套红「下转第 XX 版 ▶」（终版显示「本号终 · 全文完」）。
3. **真实多栏正文与竖向栏线（Multi-Column Rules）**：头版正文真正分 3 栏（16:9 下 4 栏/双栏并置），栏间 `1px` 墨黑细竖线，首段带黑底反白「首字下沉」；通用稿无额外专栏字段时，自动用口播实文与「本期要目」索引框填满头版。
4. **网点传真照片（Halftone Engraving Photo）**：双框报纸相框 + 高对比灰度与网点叠加 + 右上角「传真照片」角标 + 打字机图注；示范稿内置 3 幅原创 SVG 线稿插图（月面「鹰」号、土星五号发射、月面脚印）。
5. **斜印套红「号外」印章与黑框引语盒**：头版自带红色双框斜印印章；`quote` 模板采用内外双黑框引语盒配巨大套红粗引号。
6. **终版剪报回执（Clipping Coupon）**：`ending` 模板的行动号召放进带虚线裁切边与剪刀标 `✂` 的报纸剪报回执框。

## 5. 各模板版式语法
- **`cover`（头版）**：大报头 + 通栏跨栏大标题 + 副题横条 + 网点主图（有图时）+ 带竖向栏线与首字下沉的多栏新闻正文 + 栏目索引标签 + 套红印章。支持 `layout`: `'classic'`（默认）、`'extra'`（纯字号外通栏）。
- **`chapter`（专版导读）**：反白墨黑整版，双米黄粗细线，套红大号版辑数，极粗居中专版标题，底部电报体注记。
- **`cards`（人物 / 专题方框版）**：带黑底/套红反白栏头的报纸方框。3 项在竖屏采用「1 通栏领衔 + 2 并列分栏」或「三联带角标横排框」，横屏采用 3 等宽带竖线报栏；4 项在竖屏 2×2 十字栏格、横屏 4 栏并列。
- **`stats`（数据公报表格）**：统一双粗黑框数据公报，带「数据公报 · STATISTICAL LEDGER」表头条与内部横竖实线单元格，重点单元格套红高亮。
- **`timeline`（时序日程表）**：竖屏为「左侧黑/红时间方框 + 中轴菱形标 + 右侧虚线分隔电讯条目」双栏日程表；横屏为带竖向分栏线的横向时间表。
- **`quote`（报纸引语框）**：双层黑框引语盒，套红粗引号突破顶框，极粗宋体分行引文，底部右对齐出处与「本报实录」标。
- **`bignum`（特号数据公报）**：双线公报框 + 超大窄体数字 + 粗黑底线 + 极粗说明标题；16:9 改为左数字右说明双栏。
- **`statement`（社论通栏大字）**：上下双粗黑线夹通栏大字，菱形铅字饰符，重点词带套红墨线底标。
- **`list`（电讯简报）**：顶部「电讯要闻」双线栏头，黑方块编号/铅点 + 细横线分隔条目；横屏 4 项及以上自动双栏加竖向栏线。
- **`bars`（印刷斜纹图表）**：带刻线参考网格（25% 间隔细虚线）的图表框，45° 铅版斜纹黑条，重点项套红条。
- **`compare`（正反对照专栏）**：统一双黑框左右两栏，中线双竖线夹黑框 `VS` 标，底部通栏「本报结语」条。
- **`steps`（行动程序表）**：黑底编号方格 + 铅字箭头连线 + 边框分格。
- **`image`（传真摄影版）**：网点双框照片 + 图注，带要点时竖屏上照下电讯栏、横屏左照右竖线专栏。
- **`code`（电报原码框）**：报纸浅米底黑框电报打印纸，方形栏标，套红关键字高亮。
- **`formula`（科学公报框）**：四角括号科学公报盒 + KaTeX 公式套红强调。
- **`ending`（终版封底）**：终版通栏标题 + 带 `✂` 虚线剪报回执 CTA + 栏目铅标 + 出版版权栏。

## 6. 动效与转场性格
- **转场**：`paper`（0.65s），新版面像一张真实报纸从下方带着轻微角度和纸影翻入覆盖旧版。
- **自定义出场动画**：
  - `pressSlam`：铅字压印感——由 1.12 倍快速砸落至 1.0 并瞬间收清，用于 `title`、`big`。
  - `inkPrint`：油墨着纸感——微距聚焦 + 墨色吃进纸面，用于 `text`、`item`、`card`、`quote`。
  - `ruleDraw`：铅线拉出动画，用于报头双线与栏目分割线。
- **焦点跟随**：`focus: true`，`--dim: 0.36`，讲过的条目墨色略淡，正在讲的条目边缘微亮套红铅线。

## 7. 三种画幅适配
- **3:4（1080×1440）**：标准单页报版。头版报头 → 通栏标题 → 宽幅网点主图 → 3 栏实文（带竖线）；内容页上下结构为主，安全区避开顶部报眉和底部字幕。
- **9:16（1080×1920）**：移动端竖屏长报。底部保留 560px 平台按钮与字幕安全区；头版与内容页紧凑排布，字号放大、行距舒展，确保手机竖屏清晰可读。
- **16:9（1920×1080）**：对开横版大报。头版改为「顶部紧凑报头 + 通栏大标题 + 下方左图右双栏实文」横幅构图；`bignum`、`image`、`cards`、`stats`、`timeline`、`list` 均切换为多栏横向排布，用满横向宽度。

## 8. 引擎建议
- 目前 `core.js` 的 `chrome(c)` 在 `renderCover()` 与 `renderAt(t)` 时 `info.cover` 行为不同（后者为 `false`），风格侧已通过同时判断 `info.cover || info.type === 'cover'` 妥善处理。
- `fitScene` 在高度略超 1px 时会触发整体缩 `--s`，重做复杂网格模板时需严格控制固定边距与最小字号，保证所有场景在三种画幅下均能保持 `--s >= 0.85` 且零溢出。
