# 地铁导视（`metro`）设计说明

## 1. 风格概念

**地铁线路图与现代公共交通导视系统**（灵感源自伦敦地铁 Harry Beck 45°/90° 拓扑线路图、东京地铁多色线路徽标及国际机场/轨交高对比导视牌）。

核心视觉隐喻：**把一切知识、流程、对比与数据，都转译为「线路、站点、站名牌、车厢 LED 屏、出口黄牌」**。哪怕画面缩到邮票大小、转成纯黑白，也能凭顶部全幅 LED 导视屏、0°/45°/90° 粗轨折线、实心/双环换乘站点和站台横贯色带一眼辨认，与其他 14 套风格彻底拉开距离。

## 2. 色板系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 导视白 `--bg` | `#F7F7F5` | 主画布底色（微暖站厅瓷砖/灯箱白） |
| 导视炭黑 `--fg` | `#1D1D1F` | 主文字、车厢 LED 顶栏、站台深色页底色 |
| 辅助灰 `--fg2` / `--fg3` | `#555860` / `#8C9099` | 副标题、备注、未到达站点 |
| 1 号线红 | `#E4002B` | 主线路色 / 警告 / 对比线 A |
| 2 号线绿 | `#00A651` | 线路色 / 通过站 / 对比线 B |
| 3 号线蓝 | `#0072CE` | 线路色 / 默认信息强调 |
| 4 号线紫 | `#8E44AD` | 线路色 / 章节轮换 |
| 5 号线琥珀黄 | `#E09F00` / `#FFC72C` | 线路色 / 支线 |
| 导视黄 `--yellow` | `#FFD100` | 出口牌（A/B/C 口）、广播警示条、重点高亮底色、终点徽标 |

- **明暗节奏**：内容页默认导视白 `#F7F7F5`；`chapter`（站台站名牌）与 `ending`（终点站）切换为深炭黑 `#1D1D1F` 站台主题，配高饱和线路色横带与导视黄字标，形成明暗交替的进站节奏。用户仍可通过 `bg: "light"` 或 `bg: "dark"` 手动覆盖。
- **线路色轮换**：随章节或场景自动切换红 / 绿 / 蓝 / 紫 / 琥珀五条线路色，车厢顶栏徽标与页内轨道同步变色。

## 3. 字体体系

在 `style.json` 中加载 `["sans", "grot", "bebas", "cond", "mono"]`：

- **中文标题 & 站名**：`"MV Grot", "MV Sans", sans-serif`（字重 900），紧致有力、无衬线几何感。
- **中文正文 & 说明**：`"MV Grot", "MV Sans", sans-serif`（字重 400/700），手机端清晰易读（3:4 正文 ≥ 36px，标题 ≥ 78px）。
- **大数字 & 线路编号**：`"MV Bebas", "MV Cond", "MV Sans", sans-serif`（Bebas 单字重 400，Cond 700），还原站牌大字号窄体编号。
- **英文副标 / 时刻代码**：`"MV Mono", "MV Grot", "MV Sans", monospace`。

## 4. 网格与安全区

- 底纸 `paint()` 绘制微细站厅瓷砖/导视网格（低对比度 60px 栅格 + 轻微灯箱边缘压暗，不干扰阅读）。
- 严格遵守三大画幅安全区：
  - **3:4（1080×1440）**：顶部 0–122px 为车厢 LED 顶栏 + 微型线路进度条，正文安全区 `ct: 170px, cb: 270px`；底部字幕居中在 `1262px`，署名条在最底 `24px`。
  - **9:16（1080×1920）**：LED 顶栏下移至 `top: 72px`（避开手机状态栏与灵动岛），正文安全区 `ct: 250px, cb: 560px`（底部 560px 避让平台按钮与字幕）。
  - **16:9（1920×1080）**：顶部 0–106px 为宽屏 LED 导视栏，正文安全区 `ct: 150px, cb: 210px`，封面、对比、步骤、时间线、图片自动启用横屏构图。

## 5. 标志性视觉装置

1. **车厢 LED 导视顶栏 + 列车线路进度条（`chrome`）**：深炭黑 LED 显示屏显示当前线路徽标、`下一站 / NEXT`、站序及确定性闪烁的信号灯；紧贴其下的微型线路条标出全片站点圆点，一只小列车图标随播放进度沿线驶向终点。
2. **0°/45°/90° 矢量地铁线路图（封面 / `steps` / `timeline` / `list`）**：严格遵守 0°/45°/90° 折线与圆弧转角规则；普通站用实心/白心彩边圆点，重点/换乘站用白心黑边双环大圆；配自定义动画 `trainMove` 让小列车沿 SVG 路径行驶。
3. **站台站名牌（`chapter`）**：横贯画面的超粗线路色带 + 中央圆角方块站号与超大中英文站牌 + 自动读取前后章节生成的「◀ 上一站 / 下一站 ▶」导视箭头。
4. **黄色出口导视牌（`#FFD100` + `#1D1D1F`）**：用于重点提示（`note`）、印章（`stamp`）、对比结论（`verdict`）、出口卡片角标（`A 口 / B 口`）与强调词高亮底带。

## 6. 各模板版式设计

- **`cover`（封面）**：完整地铁线路图海报。3:4/9:16 为「上部线路图例标题盒 + 下部多线 0°/45°/90° 交汇线路图 + 右下角巨型线路编号徽标」；16:9 为「左 44% 图例栏 + 右 56% 宽幅地铁网络灯箱」。支持可选字段 `d.stations`（站点名数组）与 `d.lineCode`（线路代号）；未提供时自动从全片章节/场景标题提取站点，适配任意通用稿。支持 `d.layout`: `'map'`（默认）/ `'compact'`。
- **`chapter`（章节页）**：深炭黑站台墙面 + 横贯彩色线路粗带 + 中央大站名牌（含圆角方块站号 + 站名 + 英文/副标）+ 上一站/下一站方向导视条。
- **`steps`（步骤）**：真正的地铁线路节点图。竖屏为左侧粗轨纵向线路 + 站号圆环 + 水平站名卡；横屏为车厢门上方横向 LCD 闪灯线路图，站点上下/齐整排布；连线描线 `draw` + 列车图标沿线推进。
- **`list`（列表）**：左侧连续彩色地铁轨道线 + 站点圆点（编号圆标 / 普通圆点 / 绿线对勾 / 红线叉 / 换乘双环重点项）+ 右侧水平站名与备注。
- **`timeline`（时间线）**：地铁历史延伸线，年份做成线路号色块徽标，节点为白心黑边换乘双环，粗彩线连接并带小列车推进。
- **`compare`（对比）**：两条不同颜色线路（默认红线 vs 绿线）分轨对比，顶部线路色横幅 + 站点式要点，中间白心黑边换乘环 `VS`，底部导视黄出口结论牌 `verdict`。
- **`bars`（条形图）**：各线路里程/耗时轨道图。每行配圆形线路号徽标 + 刻度底轨 + 粗彩色轨道条 + 终点换乘圆环（重点项末端停靠迷你列车图标）+ `MV Bebas` 数值。
- **`stats`（数据卡）**：站厅运行信息屏，每张卡顶部带独立线路色条与编号，重点项切为导视黄高对比面板。
- **`cards`（卡片）**：站厅出口/换乘导视牌，顶部出口徽标条 + 方向箭头 `↗`，重点卡切换导视黄顶条。
- **`bignum`（大数字）**：站台里程/倒计时巨型站牌，超大 `MV Bebas` 数字 + 下方地铁刻度标尺与移动列车点。
- **`statement`（一句话）**：车厢广播导视牌，顶部导视黄 `BROADCAST · 车厢广播` 横条 + 深框播报正文。
- **`quote`（引用）**：站厅灯箱金句牌，左侧四色并行地铁线路竖带 + 大号黑体引文 + 站牌式出处。
- **`code`（代码）**：行车调度终端屏幕，顶栏红黄绿轨交信号灯 + 文件名 + `SYS · OK` 状态标，高亮行使用导视黄竖标。
- **`formula`（公式）**：调度计算板，白底粗框 + 顶栏蓝线标 + 居中公式 + 站点式说明。
- **`image`（图片）**：站厅金属灯箱展板，深灰边框 + 顶部线路色指示条 + 右下角图号。
- **`ending`（结尾）**：深炭黑终点站台，顶部五色线路汇合带 + `TERMINAL · 终点站` 导视黄牌 + 出口黄 CTA 横幅 + 乘车票风格署名区。

## 7. 动效与转场

- **转场**：`push`（`dur: 0.48s`, `dirs: ['left']`），新页自右向左干脆推入，像地铁列车驶入下一站，快速利落无拖沓。
- **出场性格**：标题 `up`（指数缓动利落上浮）、标签 `wipe`（导视牌刷出）、站点/列表项 `slideX`（横向进站）、徽标/站圆 `pop`（清脆弹出）、轨道线 `draw`（描线延伸）、自定义 `trainMove`（小列车沿路径确定性行驶，仅由时间 `t` 计算）。

## 8. 引擎建议

- 当前全部视觉与动效均已通过 `templates` 覆盖与 `MV.kinds.trainMove` 完整实现，无需改动引擎。
- 若未来希望转场具备更强的「列车疾驰速度线」质感，引擎可考虑支持自定义转场钩子注册（类似 `MV.kinds`）。
